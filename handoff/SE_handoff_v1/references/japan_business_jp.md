# 일본 비즈니스 일본어 reference (B2B 도매·유통·벤더 응대)

## 호칭

| 상대 | 호칭 | 비고 |
|---|---|---|
| 개인 (이름 알 때) | `{성}様` | 본명 풀네임 받으면 즉시 `様` 로. 닉네임·이름만 X |
| 개인 (이름 모름) | `ご担当者様` | 첫 컨택 시 디폴트 |
| 회사 (법인 전체) | `{社名} 御中` | `様` 와 같이 쓰지 않음 — `〇〇株式会社 御中` |
| 부서 | `{部署名} 御中` 또는 `{部署名} ご担当者様` | |

**금지 패턴**: `〇〇様御中` (이중 경칭), `〇〇さん` (비즈니스 X — 친근/사내용), `〇〇くん/ちゃん`.

## 메일 정형 (도매·유통·벤더)

### 오프닝 (첫 줄)
- 신규: `お世話になります。{自社名}の{名前}と申します。`
- 기존: `いつも大変お世話になっております。{自社名}の{名前}でございます。`
- 오랜만: `ご無沙汰しております。`

### 클로징
- 일반: `何卒よろしくお願い申し上げます。`
- 회신 요청: `お手数をおかけいたしますが、ご確認のほどよろしくお願い申し上げます。`
- 급함 (절대 「急ぎでお願いします」 X — 무례): `誠に恐縮ですが、{日付}までにご返信いただけますと幸いです。`

### 사과
- 가벼움: `恐れ入りますが` / `お手数をおかけいたしますが`
- 정식: `誠に申し訳ございません。`
- 변명 X — 사실 → 사과 → 대응책 순.

## 자주 쓰는 비즈니스 표현

| 한국어 의도 | 일본어 |
|---|---|
| 견적 보내주세요 | `お見積もりをご提示いただけますでしょうか` |
| 발주하겠습니다 | `下記のとおり発注させていただきます` |
| 납기 확인 | `納期につきまして、ご確認いただけますでしょうか` |
| 재고 확인 | `在庫状況についてお伺いしたく` |
| 가격 협의 | `お取引条件について、ご相談させていただきたく` |
| 검토 후 회신 | `社内にて検討の上、改めてご連絡差し上げます` |
| 즉답 회피 | `一旦お預かりし、確認次第ご連絡いたします` |
| 거절 | `誠に恐縮ですが、今回は見送らせていただきたく存じます` |

## 톤 룰

1. **断定 X** — 「~です/~ます」 보다 「~かと存じます」「~いただけますと幸いです」 가 안전.
2. **直接的な要求 X** — 「~してください」 X → 「~いただけますでしょうか」 O.
3. **사내 합의 톤** — 즉답 X. 「社内で確認の上」 한 step 두는 게 디폴트.
4. **메일 1통 = 1논점** — 여러 안건은 줄바꿈+소제목 또는 별도 메일.
5. **이모지·! X** — 비즈니스 메일엔 일체.

## 한자/표기 주의

- `致します` 보다 `いたします` (사 양손에 보내는 동작이라 가나가 정중)
- `下さい` 보다 `ください` (의뢰 의미는 히라가나)
- `宜しく` 보다 `よろしく` (히라가나 표준)
- 사명·고유명사는 정식 표기 그대로 (株式会社·有限会社 줄임 X)
