# 일본 회계·결제 reference (B2B 도매·유통)

## 税込 / 税抜 (소비세 표기)

- **2021/4 부터 「総額表示義務」** — 소비자 대상은 税込 표시 의무. B2B 견적·계약은 税抜 베이스 흔하지만 **반드시 둘 다 명시**.
- 표기 권장: `100,000円（税抜）/ 110,000円（税込）`
- 견적서·계약서·인보이스 모두 「税抜・税率・消費税額・税込」 4개 분리 표기가 후일 트러블 회피.
- 소비세율: **10%** 표준 / **8%** 경감세율 (식품·정기구독신문). 도매 대부분 10%.

## インボイス制度 (적격청구서등 보존방식, 2023/10~)

- 매입세액공제 받으려면 거래처가 **「適格請求書発行事業者」** 등록 필수.
- 등록번호 형식: `T + 13桁` (예: `T1234567890123`)
- 신규 벤더 등록 시 **반드시 확인 항목**:
  1. 적격청구서발행사업자 등록 여부 (등록번호 받기)
  2. 미등록이면 매입세액공제 불가 → 단가 협상 시 소비세 부분 협의 필요
- 국세청 공표 사이트에서 등록번호 검증 가능: `https://www.invoice-kohyo.nta.go.jp/`

## 振込 (송금) 관례

- 일본 B2B 디폴트는 **銀行振込**. 카드·수표 거의 X.
- **振込手数料 부담**:
  - 관례적으로 **支払側(매수자) 부담** 이 표준
  - 큰 거래처가 「弊社振込手数料差引き」 명시하면 매도자 부담
  - 계약서·발주서에 명시해두는 게 안전
- **支払サイト** (결제 주기): 「月末締め翌月末払い」(月末締翌月末) 가 가장 흔함. 「20日締翌月10日払い」 등도 있음.
- 영업일 기준 — `銀行営業日` 명시 (토일·축일 제외).

## 인보이스(請求書) 필수 기재 항목 (적격청구서)

1. 발행자명 + 등록번호 (T+13桁)
2. 거래연월일
3. 거래내용 (경감세율 대상은 표시)
4. 세율구분별 합계금액 + 적용세율
5. 세율구분별 소비세액
6. 수령자명

→ 1개라도 누락이면 매입세액공제 불가.

## 원천징수 (源泉徴収) — 도매에선 원칙 X

- 도매·물품 거래는 원천징수 **대상 외**.
- 단, 컨설팅·디자인·번역 같은 「報酬・料金」 결제는 10.21% 원천징수 (法人 지급은 X, 個人事業主 대상).
- B2B 도매 견적·인보이스에 「源泉徴収」 줄 들어오면 거래 성격 재확인.

## 결제 통화

- 국내 거래는 **JPY 일원**. 외화 표기는 환차익·환차손 회계 처리 필요.
- 수입 거래는 USD/EUR 통상 — 사내 환산환율 (社内レート) 결정 룰 + 차이 계상 룰 사전 합의.

## 주의 (한국식 사고 그대로 가면 사고)

- 「세금계산서」 ≠ 「請求書」. 일본은 영수증(領収書) vs 청구서(請求書) 별개. 통상 청구서로 결제 → 입금 확인 후 영수증.
- 「견적서 = 발주서」 X. `見積書 → 発注書(注文書) → 請求書 → 領収書` 4단계 분리.
- 도장 (角印/会社印) — 메일 PDF 거래 늘었지만 정식 계약은 아직 도장 요구하는 회사 多.
