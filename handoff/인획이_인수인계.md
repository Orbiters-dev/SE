2. **생성 도구 실행**:
   ```bash
   python tools/plan_weekly_content.py --distribution "tips:8,brand:6,k_babyfood:3,knowledge:3" --avoid-xlsx "<이전 주 기획안.xlsx>"
   ```
   - **`--avoid-xlsx` 는 필수** — 이전 주 주제(C열)를 금지 목록으로 주입해 주간 중복을 막는다 (2026-07-21 주제 중복 사고 재발 방지).

   - `--dry-run` = 트렌드 스크래핑만 (엑셀 생성 없음).
3. **생성 후 검증 (의무)** — 아래 「7. 생성 후 검증」 수행.
4. **저장**: 출력 파일(`.tmp/weekly_content_plan_YYYYMMDD.xlsx`)을 지정 폴더에 `{월}_W{N}_기획안.xlsx` 로 복사.

## 4. 카루셀 5슬라이드 표준 구성 (필수)

| 슬라이드 | 역할 | 내용 |
|----------|------|------|
| **S1 표지** | 후킹 | 메인 사진 + 제목 텍스트 오버레이 (소제목+대제목) |
| **S2 훅·문제 제기** | 공감/의문 | "○○ 모르고 있지 않나요?" "이게 정답?" 식 의문 던지기 |
| **S3 핵심 정보1** | 데이터 | 월령별·종류별 비교표, 한눈에 보는 표, 사진 비교 |
| **S4 핵심 정보2** | 실행 | 단계 가이드, 체크리스트, NG vs OK 사례 |
| **S5 CTA** | 액션 | 저장/팔로우/프로필 유도. CTA 캐치프레이즈 대표 1개 |

### 썸네일(S1) 필수 포맷
- **subtitle (소제목)**: 카테고리 태그. 배경색 있는 짧은 라벨. 예: 「育児のコツ」「ママのそれ知りたかった！」「知っておきたい」「意外と知らない！」
- **title (대제목)**: 핵심 키워드 2~3단어, 크고 굵게, 키워드 하나 색상 강조. 예: 「赤ちゃんの**お昼寝**チャート」「**夜泣き**対策6選」「**マグ投げ期**、どう乗り越えた?」
- 비주얼: 아기/제품 실사진 위 텍스트 오버레이 (하단 배치). 강조 색상: 핑크/코랄 (브랜드 컬러). 폰트: 흰색 or 진한 색 + 그림자/반투명 배경으로 가독성 확보.

### 슬라이드 제목 룰 (2026-04-27)
- 슬라이드 제목은 **6~10자 이내 핵심 어구**만. 동사·빈도·이유는 설명 줄(2번째 줄)로 분리.
  - 좋은 예: 「日焼け止めはこまめに」 / 「水分はストローマグで」 / "선크림은 자주"
  - 단, **동사가 빠지면 의미가 모호해지면 동사를 살린다**: 「汗はやさしく」❌ → 「汗はやさしく拭く」✅
- 전 슬라이드 제목의 글자 수·문법 패턴 통일감 유지.
- **리스트형(○○ 5선/대책/방법/꿀팁) 콘텐츠 항목은 명사 라벨이 아닌 행동 동사형**으로: "UV対策"❌ → "UVクリームを朝＋2時間ごとに塗る"✅. 비교·분류형("○○ 3종 비교")은 명사 OK.

## 5. 카피 톤 가이드 (6~24개월 맘 타겟)

타겟은 **6~24개월 아이를 키우는 엄마**. **정보 전달성 + 친근함의 중간 톤**.
한 줄 정의: **"옆자리 동네 언니가 알려주는 육아 정보" 톤.**

| 영역 | OK (정보+친근) | NG ① 딱딱·비즈니스 | NG ② 너무 캐주얼 |
|------|----------------|--------------------|-----------------|
| 어휘 | 日焼け止め / お水 / お出かけ / お顔 | 紫外線対策 / 水分補給 / 外出 | — |
| 어미 (JP) | 〜のがおすすめ / 〜が基本 / 〜が目安 / 〜が◎ / 〜が安心 | 〜すること / 〜の必要がある / 〜を推奨 | 〜してね / 〜していこう / 〜してあげて |
| 어미 (KO) | "~해주세요" "~좋아요" "~정도가 적당해요" "~안심" | "~할 것" "권장" "필수" "기본 원칙" | "~해봐~" "~하자!" "~하기♡" |
| 표현 | こまめに / ちょうどいい / 目安 / おすすめ / 딱 좋아요 | 黄金ルール / 必須 / 推奨 / 適切に | テンション系 과잉 이모지 |

**규칙:**
- 한자어 비율 낮추기 → 히라가나 + 부드러운 외래어 활용
- **오노마토페(ポンポン·シュッ·トントン 등)는 카루셀 전체에서 0~1개만.** 남발 금지. 한국어도 "톡톡·칙·박박" 남발 금지 — JP와 매칭되는 1개만
- "黄金ルール" "必須" "推奨" "適切に" 같은 마케팅·교과서 표현 금지
- 한국어도 "~해요" "딱 좋아요" 친근 존댓말. "~할 것" "필수" 금지
- 의료적 단정·논쟁성 육아 어드바이스·경쟁사 비판 금지

### 자연스러운 일본어 검증 (2026-04-27)
- 한국어→일본어 직역 후 반드시 "이게 일본인이 실제 쓰는 일상 표현인가?" 체크
- 의심 가는 카타카나는 한자/히라가나 표현이 메인인지 확인: UVクリーム❌ → 日焼け止め✅
- 자신 없으면 일본 사이트(クックパッド·LDK·ベビカム·ピジョン 등) 웹 검색으로 실제 쓰임새 확인
- 일상 표현 예시: 日焼け止め(선크림) / 虫除け(방충제) / 汗拭きシート(땀티슈) / 重ね着(겹쳐입기) / おくるみ(속싸개) / 寝かしつけ(재우기)
- 지양 한자어: 相棒 / 身軽 / 健やか / 人体工学 (→ こだわり設計·やさしい設計 등으로 풀기)
- 과한 비즈니스 정중체 지양: 「お飲みの際」「ご使用になられる」❌ → 「飲む時に」「使うとき」✅. 「お子さま」보다 「赤ちゃん」이 따뜻함

### 육아 수치 사실 검증 (2026-04-27)
- 카피에 들어가는 **양·빈도·시간·온도·월령 기준은 의학·육아 상식과 일치**해야 한다. 추정·짐작으로 수치 창작 금지.
- 잘못된 예: "30分〜1時間に一口" (탈수 위험 정보) — 실제 사고 사례
- 기준이 모호하면 정확한 양 대신 "こまめに" "喉が渇く前に" 같은 빈도 어휘로 대체
- 의심 가면 일본 소아과·육아 사이트(ベビカム·コドモエ·ピジョン·厚労省)로 검증

## 6. CTA 캐치프레이즈 규칙 (필수, 2026-04-22 확정)

모든 기획안에 **CTA 캐치프레이즈 후보 5개** 필수. 다음 3가지 톤만 사용 (혜택훅·쿠폰·DM 단독 금지):

| 톤 | 기능 | 액션 | 예시 |
|----|------|------|------|
| 1. 호기심 어그로 + 프로필 유도 | 궁금증 한 줄 → 프로필에 답 | 프로필 링크 | 「"結局どれがいいの…？" の答え、プロフィールに全部📌」 |
| 3. 저장 유도 | 다시 볼 가치 강조 | 저장 + 팔로우 | 「迷ったら保存🔖 月齢別ガイドはフォローで」 |
| 4. 공감 소속감 | "같은 고민 엄마 있어요" 톤 | 팔로우 OR 공유(예외) | 「同じ悩みのママ友いたら、そっとシェアしてあげて🤍」 |

- **메인 액션 = 팔로우 OR 프로필 링크가 기본.** 쿠폰 코드·DM·외부 사이트 방문 등 다른 단독 액션 금지 (보조로만 가능)
- 예외: 4톤 + 정보형(가이드/체크리스트) 콘텐츠 → "공유(シェア)" 액션 허용
- 5개 분포: 1톤 2개 / 3톤 1~2개 / 4톤 1~2개
- 카테고리별 대표 1개 선정: brand→1톤 / tips·knowledge→3톤(저장) / Q&A·고민 공감형→4톤 / 친구 공유 가치 큰 정보형→4톤(공유 변형) 가능
- 각 후보는 **JP 원문 + KO 번역 병기**. 대표 1개는 S5 CTA 슬라이드 대제목으로 사용
- Why: IG 운영 KPI가 "팔로워 누적 + 프로필 트래픽" 2개에 집중. 산만한 액션은 이탈 유발.

## 10. 경쟁사 출처 활용 규칙 (2026-05-03 신설 — 베끼기 금지)

경쟁사 게시물(ピジョン, b.box, Combi 등)을 출처로 쓸 때 **그 안의 정보를 그대로 옮겨 적지 말 것**.

**Why:** 과거 기획안 2건이 ピジョン 단일 게시물에서 구조까지 거의 그대로 가져와 (a) 차별화 실패 (b) 표절 리스크 (c) 브랜드 관점 없는 평면 콘텐츠가 됨.

**작성 절차:**
1. 경쟁사 게시물 = 출발점일 뿐. 거기서 멈추지 않는다
2. 추가 리서치로 보강: 厚労省·소아과학회·公的기관 가이드라인 / 학술 논문 / 다른 브랜드(b.box, Combi, Richell) 사례 / K-육아 인사이트·레시피
3. 그로미미 자체 가치 1개 이상 녹이기 (PPSU·역지밸브·360° 핸들·K-육아)

**출처 표기:** ① 1차 출처(경쟁사 게시물) + ② 보강 출처(공식기관/논문/다른 브랜드) **둘 다 명시**.
형식: `1차: ピジョン IG「○○」 / 보강: 厚労省 ◯◯ガイドライン + b.box ○○ 투고`

**자체 점검:** 경쟁사 1개에만 의존한 항목 없는가 / 캡션이 경쟁사 본문과 비슷하지 않은가 / 출처란에 1차+보강 둘 다 있는가

## 11. 생성 후 검증 의무 (2026-07-21 신설)
