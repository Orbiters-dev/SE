DM에서 해시태그·발송 정보·정책 같은 구체 정보를 안내할 때, **그 자리에서 직접 enumerate**해서 명시한다. 「ご契約時にお伝えしたハッシュタグをご記載ください」「ガイドラインをご確認ください」같이 외부 자료로 떠넘기지 않는다.

**Why:** 2026-05-04 今西様 케이스. 캡션 해시태그 안내 시 「ご契約時にお伝えしたハッシュタグを必ずご記載いただけますと幸いです」로 작성 → 세은 「해시태그 뭔지 알려줘. 항상 ~~에서 체크하셔라 이렇게 하지 말고 니가 직접 알려줘야 돼」 질책. 인플루언서가 다시 계약서·가이드라인 뒤져야 해서 비효율 + 누락 위험.

**How to apply:**
- ❌ "ご契約時にお伝えしたハッシュタグをご記載ください"
- ❌ "ガイドラインに記載のとおりにお願いします"
- ⭕ DM 본문에 「#グロミミ #grosmimi #ストローマグ #スマートマグ #PPSU」 직접 enumerate
- 제품·월령 메모리에서 룰 조회해서 정확한 값 채우기 (PPSU/ワンタッチ → +#PPSU, ステンレス → 베이스만)
- 해시태그뿐만 아니라 메일 주소·발송 일정·정책 안내 등 모든 구체 정보에 동일 적용
