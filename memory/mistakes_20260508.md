세은이 참고 릴스 2개 줬을 때 본질을 못 잡고 검색 4번 다 헛돔. 마지막에 세 번째 참고 릴스 (@rin_mama0805) 받고 나서야 본질 보임.

**놓친 본질:**

- 캡션 톤: 길고 (4-7줄) 감성 스토리텔링
- 핵심 해시태그: `#台所育児` `#赤ちゃんのいる生活` `#1歳` (요리 키워드 X)
- 사이즈: 마이크로~중형 (5K-50K)

## 4번 실패 원인 (반복 금지 패턴)

### 1) 참고 릴스 호스트 자체를 깊이 분석 안 함
- @deanna.hauk / @macygubitoso 메타만 fetch (caption + hashtag 5개)
- **호스트의 다른 30개 포스트 + bio 분석을 안 했음** → 본질을 첫 fetch에서 못 잡음
- 마지막 시도에서야 `apify/instagram-profile-scraper resultsType=posts` 로 30개 포스트 + 해시태그 분포 분석함 — 이걸 처음에 했어야 함

### 2) 캡션 키워드 필터에 의존
- "クッキング" "料理" "お手伝い" 등 broad 키워드로 가정
- 실제 본질 호스트 (@rin_mama0805)의 캡션엔 그런 키워드 거의 없음 → "台所育児" 같은 라이프스타일 태그가 본질
- **캡션 키워드 매칭은 본질 매칭 대체 불가**

### 3) reels_only 필터 버그 미해결로 우회
- V2에서 Apify hashtag scraper의 `searchType=reels`가 jp 해시태그에 0건 → 좌절
- V3로 V1 raw 재활용 → image post 위주 fallback (영상 매칭 X)
- **Apify hashtag scraper의 video metric 누락 한계**를 인지하면서도 다른 actor 탐색 안 함

### 4) "유추 가능한 거 묻지 마" + "직접 파악" 룰 위반
- 세은이 두 미국 릴스 줬을 때 "그로미미 JP 컨셉이라고 단정"하고 미국/일본 안 물음
- 정정 후에도 본질 톤 분석 깊이 부족
- **참고 자료 호스트는 항상 호스트 자체를 30개 포스트 + bio + 해시태그 분포로 깊이 분석부터**

## 영구 룰화

**Why:** 세은이 4번 실패 후 직접 다른 참고 릴스 찾아서 줬음. 본질 못 잡으면 Apify credit + 시간 모두 낭비.

**How to apply:** 참고 릴스/콘텐츠 받으면:
1. **호스트 프로필 + recent 30 posts** 무조건 먼저 fetch (`apify/instagram-profile-scraper resultsType=posts resultsLimit=30`)
