2026-09-07 세은 확정, **2026-10-06 수취인명·주소 영문/카나 병기로 갱신** — 앞으로 송금 정보를 전달/요청할 때 아래 2블록 표 형식으로 고정.

## 송금 정보
| 항목 | 내용 |
|---|---|
| 송금액 | 통화+금액 (예: JPY 30,000, 税込 여부 표기) |
| 수취인명 | **한자 / カタカナ / English 3중 병기** (2026-10-06 세은 지시로 갱신 — 예: `越川 寛子 / コシカワ ヒロコ / Koshikawa Hiroko`). ⚠️요미가나 애매하면 본인 확인. |
| 은행명 | 한국어 (은행코드 ****) / 영문 — 예: 미쓰비시UFJ은행 (은행코드 0005) / MUFG Bank, Ltd. |
| 지점명 | **지점코드로 실제 지점명 조회 후 기입** (코드만 X). 예: 金沢支店 (지점코드 507) / Kanazawa Branch (507). ※계약서엔 店番号만 있는 경우 많음 → firecrawl로 조회 |
| 계좌 종류 | 보통예금 / Ordinary (Futsu) |
| 계좌번호 | 숫자 |
| 통화 | 일본 엔 / JPY |

**미확인 채우기 룰:** 은행코드·지점명은 계약서에 없으면 조회해서 채운다(三菱UFJ=0005, 店番号→firecrawl `店番号 NNN 支店名`). 코드만 적고 넘기지 말 것 (2026-09-09 교정 「코드로 무슨 지점인지 찾아야 될 거 아니야」).
