## 4. "Ad code 칼럼 0건" 오보 — 칼럼 인덱스 가정 (MEDIUM)

- 코드가 읽던 col 27("Ad code", 1건)만 보고 "시트에 코드 0건" 단정 보고. 실제 WL code는 col 15에 87건.
- 세은: 「sheet에 코드 칼럼 뭐가 0이라는 거야?? WL code 칼럼 확인하면 돼」
- 교훈: **시트 칼럼 내용을 단정 보고하기 전에 헤더 행을 직접 읽어 칼럼명↔인덱스 대조.** 코드의 칼럼 매핑(r[27] 등)을 시트 실물 검증 없이 신뢰 X — 5/18 "코드 주석 그대로 신뢰 X" 룰의 시트 버전.

## 5. bebimon "다르다" 설명 — 주체 불명확 (MEDIUM)

- "광고 게시물과 시트 핸들 약칭이 불일치" 설명이 사람이 다르다는 말처럼 읽힘 → 「뭐가 다르다는 거야?? 똑같은 거 맞아 둘이」
- 동일인 여부는 게시자 username API 조회로 처음부터 검증 가능했는데 약칭 추측 단계에서 보고.
- 교훈: 매칭 실패 보고는 무엇이(사람/게시물/코드) 불일치인지 주체 분리 + 동일인 여부는 게시자 계정으로 검증 후 보고.

## 6. 단위 통일 과적용 (MEDIUM)

- 「단위 전부 통일해. 전부 K로」 → 금액까지 K/M 적용 → 「view 수 맞추라고 한 거지 금액은 액수 그대로」 정정.
- 교훈: 표기 일괄 변경 지시는 적용 범위(개수/금액/비율)를 좁게 시작. 금액은 정산 대조용이라 풀 자릿수 디폴트.

## 7. 월별 정리 위치 — 스크린샷 = 위치 지시 (MEDIUM-HIGH)

- 기간 칩 스크린샷 첨부 + "여기에 월별 관리 항목 하나 더" 지시를 받고 페이지 하단 카드로 배치 → 「밑에 넣을 게 아니라 항목 중 하나로 만들라니까」 재지시.
- 교훈: **UI 요청에 첨부된 스크린샷은 위치/형태 지시.** 첨부 화면의 요소(칩·토글)에 직접 결합하라는 뜻으로 해석.
