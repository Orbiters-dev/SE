세은이 인플루언서 건을 「○○様 전부 완료」라고 알리면, 그건 **마무리 멘트 DM을 작성하라는 신호**다. 메모리 상태 갱신은 부수 작업이고 본 작업은 DM.

**Why:** 2026-06-16 児玉様(ohana) 「전부 완료」에 나는 influencer_ohana.md만 업데이트하고 끝냄 → 세은 「쌰갈 마무리 멘트 디엠을 줘야 할 거 아냐」 강한 교정. DM checklist 7번(全完了 마무리)이 이미 있는데도 「완료」를 단순 상태 보고로만 받았다.

**How to apply:** 인플루언서 작업이 「완료/끝/자료 다 받음」으로 들리면 → 즉시 STEP 12 마무리 DM(자료 수령 ack + 협력 감사 + (유상시) 입금줄 통합) 초안 + Harness → 보여주기. 메모리 갱신은 그 다음. [[feedback_after_docuseal_send_step65_dm]] [[feedback_paid_closeout_two_lines]]
