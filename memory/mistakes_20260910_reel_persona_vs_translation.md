# reel-translator 「페르소나」 = 번역가 페르소나 텍스트, 번역 결과물 X

**사고 (2026-09-10):** IHV4 릴스 자막 번역 후 세은 「페르소나 ㄱㄱ」 → 번역 표(영/일/한) 재제출. 「아니 페르소나만 주라고」 → 일본어 자막만 재제출. 「야 페르소나만 주라고. 번역 페르소나 장난하나 이게」 강한 교정.

**정정:** 「번역 페르소나」 = @grosmimi_japan 자막 번역가의 **역할·톤·원칙을 서술한 페르소나 프롬프트 텍스트** (SKILL의 페르소나 정의를 재사용 가능한 블록으로). 번역된 자막이 아니다. 과거 「SBV 번역 페르소나 초안」과 동일 산출물 종류.

**How to apply:**
- reel-translator 맥락에서 「페르소나」 = 번역가 페르소나 서술문 출력 (일본어 지시문 형태). 번역 자막 X.
- 「~만 주라고」 = 딱 그것만. 표·번역·주석·질문 덧붙이지 마.
- 산출물 종류 애매하면 되묻지 말고 SKILL/과거 산출물명(「번역 페르소나 초안」)으로 종류 특정 후 그것만.
