2026-07-07 인플루언서 DM 세션. 1턴 = 「金原です」 서명된 음원/라벨 질문(金原 정확). 2턴 = 서명·핸들 없는 「かしこまりました 今月中に投稿させていただきます」 → 직전 턴 金原을 **자동 상속**해서 계속 金原으로 ack 작성 → 세은 「西村様 이 사람임」 정정.

**Why:** 매 DM 인물 재식별 룰 재위반([[mistakes_20260611]]). 서명 없는 메시지를 직전 화자로 관성 처리. 게다가 **결정적 단서를 무시**: 金原은 7/8(水)18시 **확정일**이 있어 막연한 「今月中」과 불일치. 西村은 5월말 예정→한 달+ 지연→7/6 「이번 달 목표」 재촉 상태라 「今月中に投稿」이 정확히 정합. 메시지 내용을 각 인플루언서 진행 stage와 대조만 했으면 조사로 西村 특정 가능(≠ 묻지 못할 판단).

**How to apply:**
- 서명/핸들 없는 답신은 직전 화자 자동 상속 X. 메시지 **내용을 후보 인플루언서들의 현재 stage·약속과 대조**해서 정합하는 쪽으로 특정. (예: 확정일 있는 사람 vs 지연 재촉 중인 사람 → 「今月中」은 후자)
- 여러 인플이 같은 posting stage일 때, 식별 단서(내용 정합)로 좁힌 뒤 확정. 정합 후보가 갈리고 본문에 식별자 없으면 그때만 세은에 「누구 건」 확인.
- 부수 교정: 「今月中 투고」 같은 가벼운 ack에도 STEP 11 「投稿前に一度共有」 사전 공유 라인 포함(下書き 확인=계약 제2조).

## 재발 2026-10-14 (金原↔井手)

서명 없는 「サムネイルとキャプションが完成」 DM을 직전 턴 金原様(캡션·썸넬 "出来次第共有" 약속)로 자동 상속 → 초안·메모리까지 金原으로 작성 → 세은 「아니 井手様이 사람임」 정정. **상속 유혹이 가장 강한 케이스(직전 턴 약속과 정확히 정합해 보임)일수록 오히려 위험** — 썸넬·캡션 대기 중인 인플이 동시에 여러 명(井手·野嶋·濵·金原)이었음. 같은 stage 대기자가 복수면 내용 정합만으로 특정 불가 → 세은에게 「누구 건지」 확인이 정답이었음. 金原 메모리 오염 롤백 비용까지 발생.
