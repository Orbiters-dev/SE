# CRM 컨텐츠 수집 키워드 테마 (2026-05-26 결정)

## 구조

**단일 테마 「育児」 + AND 두 버킷**

### 위 버킷 (any of) — 베이비 카테고리
```
ストローマグ / マグ / ベビーマグ / 哺乳瓶卒業 / コップ飲み /
赤ちゃん / 新生児 / 乳児 / 幼児 / 0歳 / 1歳 / 2歳 /
ベビー / baby / toddler / infant / newborn
```

### 아래 버킷 (any of) — 부모 맥락
```
育児 / 子育て / ワンオペ / 母乳 / 離乳食 / 月齢 /
赤ちゃんのいる暮らし / ベビスタグラム / 育休 /
mom / mother / mommy / parent / parenting
```

**위 + 아래 동시 hit 만 채택.** `baby` 단독으로 연인 호칭 false positive 잡히는 것 → `mom`/`parenting` 동시 조건으로 부모 맥락 강제.

## 폐기한 분리축 (5/26 결정 근거)

1. **ストローマグ 별도 X** — 마그 hit 컨텐츠는 거의 다 育児 키워드 동시 충족 (구조적 겹침). dedup 룰 박는 운영 비용 > 분리 이득. 마그 컨텐츠 분석은 육아 풀에서 직접 발견 가능.
2. **グロミミ 별도 X** — 분류 의도가 현재 운영에 적용 안 됨.
3. **プレママ 별도 X** — 지금 콜라보 못 함 + 둘째 임신 풀은 育児에서 어차피 잡힘.

## Exclude 키워드 (기존 그대로 유지)

`犬/猫/ペット/アニメ/AI/コスプレ/Vtuber/政治/婚活/筋トレ/化粧/お菓子/ネイル` 등 비육아 잡음.

## 핵심 인사이트

- **AND 두 버킷 = 각 테마 내부 정확도 향상**, 테마간 dedup에는 X
- 테마 다 합쳤어도 AND 구조로 false positive 충분히 거름
- 운영 비용 vs 분리 이득 — 분리 목적이 명확하지 않으면 통합이 정답
