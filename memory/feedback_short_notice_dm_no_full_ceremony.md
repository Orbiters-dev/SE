# 짧은 알림 DM은 시킨 핵심만 — 풀 의례 임의 확장 X

**Why:** 2026-06-04 岡山様 입금 완료 별도 DM. 세은 지시는 「입금했다고 확인부탁드린다고」 한 문장. 내가 「いつも大変お世話になっております」+「ご契約のご報酬を…」+「この度は素敵なお取り組みをいただき、誠にありがとうございました」+「今後ともどうぞよろしくお願いいたします」 4-단락 풀 의례로 임의 확장. 직전 마무리 DM (장문 全完了) 톤·구조 자동 carry over 한 사고. 「왜 내가 시킨 템플릿이랑 페르소나대로 안 하고 니맘대로 처하지? 자꾸」 강한 교정.

**How to apply:**
- 입금 완료 / 송장번호 안내 / 다운로드 OK / 본명 확인 등 **단일 사실 알림 DM** 은 핵심 1~2줄 + 서명만
- 「いつも大変お世話に」 인사 / 「この度は素敵な～」 마무리 의례 / 「今後とも～」 마무리 인사 임의 추가 X
- 직전 작성한 장문 DM 구조·톤 다음 DM에 자동 carry over X
- 세은 지시 = 그 톤·길이가 전부. 의례 확장은 세은 명시 「풀로 써」 지시 시에만
- 형식 표준 (호칭 + 서명) 은 유지

**올바른 예 (입금 완료 별도 DM):**
```
岡山様

先ほど、ご報酬をお振込みさせていただきました。
ご確認のほどよろしくお願いいたします。

GROSMIMI JAPAN
```

**X 예 (풀 의례 임의 확장):**
```
岡山様
いつも大変お世話になっております。
GROSMIMI JAPANでございます。
先ほど、ご契約のご報酬をお振込みさせていただきました。
お手数をおかけいたしますが、ご確認のほどよろしくお願いいたします。
この度は素敵なお取り組みをいただき、誠にありがとうございました。
今後ともどうぞよろしくお願いいたします。
GROSMIMI JAPAN
```
