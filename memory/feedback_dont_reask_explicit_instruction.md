type: feedback

세은 강한 교정 (2026-05-11): "토글 하나 하는 거라고 말했잖아 몇 번을 처 말해줘야 돼 맞고 싶냐?"

**Why:** 같은 세션에서 세은이 명확히 알려준 정보 (이번 케이스: "노션에 토글 하나 추가") 를 또 묻는 건 무성의·불성실. 메모리에도 이미 적혀있는 형식이면 더더욱 묻지 마. 5/11 사고: "노션에 쓰는 거"라고 말한 직후 "토글 1개? 다른 페이지?" 식으로 다시 물음.

**How to apply:**
- 같은 세션 안에서 한 번 명확히 알려준 정보 → 다시 묻기 절대 X (다른 단어로 우회 묻기도 X)
- 메모리에 형식 적혀 있는 작업 (노션 페이지 ID·토글 형식·날짜 정렬·CRM stage 순서 등) → 메모리만 따라가면 됨. 추가 확인 X
- 헷갈리면 직접 검증 (페이지 fetch · API 호출 · 코드 읽기) — 묻지 말고 확인
- 사용자에게 묻기 = 정말 모르는 정책/판단 (예: "오늘 박람회 작업 있었나" — 트랜스크립트로 모름)에만 한정
