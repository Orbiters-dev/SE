# SKU 단순 표기 (보고서용)

내부 보고서에서 SKU 표기는 **stainless / ppsu / fliptop** 3종만 사용. 색상·용량 명시 X.

## 매핑 표

| 원래 제품명 | 단순 표기 |
|---|---|
| ステンレスストローマグ (200ml/300ml, 모든 색상) | **stainless** |
| PPSU トレーニングマグ / PPSU ストローマグ (200ml/300ml, 모든 색상) | **ppsu** |
| ワンタッチ式ストローマグ / 원터치 머그 (모든 색상) | **fliptop** |

## 주의

- 원터치 빨대컵 = **fliptop** (ppsu 아님). 2026-05-07 세은 교정.
- 광고 이름의 "One Touch" / "Fliptop" 도 fliptop으로 표기 (예: "AD F | Fliptop | coni" → fliptop)
