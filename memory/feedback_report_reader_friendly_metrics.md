세은 교정 (2026-10-02, 삐삐 RPP 키워드 매핑 HTML): 내가 만드는 HTML은 **보고용**이라 보고받는 사람(대표님)이 알아들을 설명을 써야 한다. 삐삐/세은만 아는 내부 지식(目安·사전/사후 판정 로직·BIDTEST·¥40캡)을 그대로 쓰면 안 됨.

**Why:** 보고용 산출물의 독자는 작성자가 아니다. 지표 정의 없이 숫자만 던지면 보고받는 사람이 오해한다(예: "目安=최종 성과"로 읽거나, 상대값을 절대값으로 착각). 실제로 이 세션에서 세은이 지표마다 정의를 집요하게 되물음 — "유입이 뭐냐"·"AMZ는 전체 검색량 아니냐"·"며칠 기준이냐"·"신규어 기준이냐 옛키워드 기준이냐"·"앵커(ストローマグ) 기준이 맞냐". 전부 **"무엇을/어느 기간/어느 범위/절대 vs 상대"가 표에 안 쓰여 있어서** 나온 질문. [[feedback_report_analytical_real_names]] "보고용=듣는사람 쉽게"의 구체화.

**How to apply:**
- 리포트 상단에 **"이 리포트 보는 법"** 해설 박스: 목적 1줄 + 각 지표를 평이하게 풀어씀(예: "라쿠텐 目安 = 라쿠텐에서 이 단어에 광고 경쟁이 얼마나 붙는지 = 수요 간접 신호") + 색/뱃지 범례.
- **지표마다 4요소 명시**: ①무엇(검색수/경쟁가/유입수) ②기간(월간/5개월누적 — 단위 다르면 ※경고) ③범위(시장 전체 vs 자사만) ④절대 vs 상대. 예: AMZ=아마존 월간 **절대** 검색량(시장전체), RKT=라쿠텐 자사유입 5개월누적, 目安=라쿠텐 경쟁(사전 지표).
- **사전 지표(넣을 가치)와 사후 성과(잘 되는지)를 분리 명시** — "이 숫자는 출발점, 실제 성과는 넣은 뒤 노출→클릭→주문 2주 추적"처럼.
- **상대값(앵커 기준)은 왜곡 소지 → 절대수치 선호.** 불가피하게 상대값 쓰면 "참고(저신뢰)"로 시각 격하(흐린 색·소제목)하고 한계 명시. (ストローマグ=100 앵커가 니치라 왜곡된 사례.)
- 라벨은 대칭·자명하게(유입→RKT로 AMZ와 대칭).
