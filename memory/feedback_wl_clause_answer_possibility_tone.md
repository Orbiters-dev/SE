인플루언서가 「계약서의 Spark Ads/ホワイトリスティング 기재는 실제 이용 예정인가, 가능성 대비인가」 물으면 답은 **「今後利用させていただく可能性に備えて契約に含めている形」**. 「実際に広告配信での利用を予定しております」 단정 X.

**Why:** 2026-06-11 鎌仲様 케이스. 워크플로우의 「ホワイトリスティング: あり / 거부 시 계약 X」 + STEP 12 광고코드 수령 흐름에서 "실제 운용 예정"을 도출해 단정 답변 → 세은 교정 「아니 이용 가능성에 대비한 기재 맞고 형태만 제대로 설명해라」. 개별 투고의 광고 운용 여부는 사후 성과 기반 세은 결정 영역이며, 사전 약속처럼 들리는 단정은 사측 운용 재량을 좁힘.

**How to apply:** WL 조항 질문 답신 = ① 「가능성 대비 기재」 한 줄 + ② 형태 설명은 워크플로우 ホワイトリスティング説明テンプレート (본인 투고 그대로 광고 표시 / 계정명·내용 유지 / 본인 투고로 보임 / IG+FB 연동 확인 부탁). 관련: [[feedback-no-internal-threshold-to-influencer]]
