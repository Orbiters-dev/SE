키워드 종류를 부를 때는 **무조건 `branded` / `competitor` / `generic` 세 가지로만 분류**한다 (2026-10-06 강한 교정, 반복 교정 "이거 몇 번 처 말하냐").

- **branded** = 자사 브랜드어 (グロミミ · grosmimi)
- **competitor** = 경쟁사 브랜드어 (써모스/サーモス · リッチェル · コンビ 등)
- **generic** = 비브랜드 일반·카테고리·기능어 전부 (ストローマグ · ベビーマグ · 水筒 · 保冷 · 漏れない · ステンレス 등). 기능/속성어도 여기로.

**Why:** 세은이 쓰는 고정 택소노미. 내가 "속성(attribute)" 같은 새 카테고리를 멋대로 만들면 리포트·구조도가 세은 분류와 어긋나고 매번 재작업.

**How to apply:** RPP·Amazon SP 등 키워드 분류·리포트·구조도에서 항상 이 3분류만 라벨로 쓴다. 保冷/漏れない 등을 "속성"으로 빼지 말 것 = generic. 새 분류 창작 금지.
