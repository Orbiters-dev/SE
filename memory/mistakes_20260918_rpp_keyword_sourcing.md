# 오답노트 2026-09-18 — RPP 키워드 효율/20슬롯 재구성 (삐삐)

세은이 매니저 피드백("풀라인업 3분류 성과 + 20슬롯 뭘로 채울지") 대응 지시. 리포트 재작성을 여러 번 반려당함. 재발방지 5가지:

## 1. 지정 대상은 지정한 것만 — 임의 병합 금지
세은이 스크린샷으로 **정확히 3개 리스팅**(ppsu_strawcup_ss·stainless_copy·onetouch_copy) 지정했는데, `line_of()`로 묶어 **ppsu_strawcup300·st_strawcup_300(별개 리스팅)을 같은 라인으로 섞음**. → "정확히 줬는데 왜 같이 분석 처했냐". **대상이 명시되면 그것만. 유사·중복 리스팅 자동 병합 금지.**

## 2. 제품 정합 필수 — 채널/제품 교차 이식 금지 (삐삐 하드룰6)
**PPSU(플라스틱·6개월·練習·漏れない) 상품에 保冷·ステンレス(스텐 속성)를 대체어로 넣음** → 제품 불일치. "PPSU에 보냉 스테인리스 왜 처넣냐". 제품별 축: PPSU=練習/6개월/漏れない/こぼれない/월령·baby / 스텐=保冷/保温/ステンレス/真空/水筒/1-2세 / 원터치=漏れない/食洗機/ワンタッチ. **넣기 전 상품 프로필(상품명·소재·월령)과 키워드 속성 대조.**

## 3. 실측 수요 없이 "제품 정합/서제스트 추측"으로 키워드 삽입 금지
ppsuストローマグ·保温 ストローマグ·ワンタッチ ストローマグ 조합 등을 **"상품명에 그 단어 있으니 정합"·"구글 서제스트에 패턴 있음"만으로** 재입찰/신규 삽입 → 실측(H10·트렌드·유입) 다 0. "수요 없는 걸 왜 자꾸 집어처넣냐". **신규/재입찰은 실측 시장수요(H10 검색량 or 라쿠텐 유입 or GT) 있는 것만.** 재입찰 정의=수요O·입찰부족(미노출)이지, 수요0은 삭제.

## 4. 소스 편협 — 우리 서치텀만 보고 "수요 키워드 부족" 오판
수요를 `amz_agg`(**우리 아마존 계정 서치텀=우리 광고 걸린 195개만**)로 봐서 "수요 키워드 20개도 안 된다"고 결론 → "장난하냐". 실제 **Helium10 Magnet 시드확장 = JP 시장 822키워드**(제품관련 93). 시장 전체 수요 소스를 안 쓴 게 원인. **RPP 대체어 = H10(아마존 시장) + 라쿠텐 점포 유입(플랫폼 직접 실수요) + RPP 실적 + US 대시보드(전환 속성) 종합.** → [[reference_rpp_replacement_3source_dsinsight]]

## 5. 이유 묻는 질문엔 고치지 말고 이유부터
"ppsuストローマグ 왜 재입찰이야?" 물었는데 바로 코드 수정함 → "반영하라는 게 아니라 이유 물은 거야". **질문(왜)엔 답부터. 수정은 지시 후.**
