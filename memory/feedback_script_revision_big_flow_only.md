인플루언서가 보낸 台本(대본/스크립트)을 수정·제안할 때, **줄별 완성 대본을 통째로 다시 써주지 않는다.** 「이런 흐름으로 구성해 주시면 좋겠다」는 **큰 구조(흐름)만** 제시.

예: ・導入（共感） ・問題提起 ・解決 ・メインポイント ・まとめ ・締め(CTA) 식 bullet 흐름.

**Why:** 대본은 인플루언서 본인의 창작·목소리. 우리가 전부 써주면 본인 톤이 사라지고 월권. 세은은 방향 가이드만 주고 인플루언서가 자기 말로 살리길 원함. 2026-06-15 坂田様 「그렇게까지 다 써 줄 필요는 없고, 큰 흐름만 써 주면 돼」.

**How to apply:** 台本 수정 = 삭제·교정 포인트 + bullet 흐름 + (필요시) 메인 테마·가이드라인 안내. 줄별 일본어 완성본 재작성 금지. 단, 세은이 "다 써줘" 명시하면 예외.
