GROSMIMI PPSU 스트로머그의 핵심 셀링 포인트 3가지 (세은 확정, 2026-04-23):

1. **PPSU素材で赤ちゃんにやさしい** — PPSU 소재로 아기에게 순함
2. **どんなに振っても漏れない** — 아무리 흔들어도 안 샘
3. **ハンドルが回転するので、赤ちゃんが自分で持って飲みやすい** — 핸들이 회전해서 아이가 스스로 잡고 마시기 좋음

**금지 표현:**
- "細めのストロー / 얇은 빨대" — 사실 아님. 쓰지 말 것.

**스트로 연습(ストロー練習) 테마 영상용 3포인트 (세은 확정, 2026-10-11 — 稲田様 건):**

1. **クロスカット** — 아이가 빠는 만큼만 나오고, 빨지 않으면 컷이 닫혀 빨대에 물이 남아 있어도 안 나옴
2. **目盛り** — 아이가 잘 마시고 있는지 눈금으로 확인 가능
3. **입이 닿는 부분에 PP 소재 비접촉 설계** — 미세플라스틱 발생 우려가 있는 PP가 아이 입에 닿지 않아 빨대 연습 아기에게 안심 (※ DM 표현은 「マイクロプラスチック発生の懸念がある「PP素材」が触れない設計」 — 「PPは危険」 직접 공격 금지 룰 유지)

**360도 회전 핸들(ハンドル)의 역할 2가지 (세은 확정, 2026-10-13 — 小澤様 테마 건. PPSU·ステンレス 공통):**

1. **최후까지 마실 수 있게** — 기울여도 그립 유지되어 마지막까지 다 마실 수 있음
2. **아이 손목 부담 방지** — 아이가 눕고 앉아 흔들고 바닥에 치는 등 격하게 움직여도 머그를 쥔 손목에 무리가 안 감

→ 테마 활용: 「元気いっぱい動き回っても手首に無理なく最後まで飲める」 (360도 회전 핸들 메인 테마)
→ **「いろんな角度から飲める(여러 각도에서 마실 수 있다)」도 소구점으로 인정** (세은 확정 2026-10-21, 三輪様 건 — 역할 2가지는 열거이지 전체집합 아님)

**밀크(ミルク) 겸용 소구 4종 (세은 확정, 2026-10-21 — 三輪様 건. 「ミルクにも使える」 메인 테마용·스텐 건에서 확정):**

1. **母乳実感 젖꼭지 교체** — ピジョン 母乳実感の乳首に替えれば 아기도 쉽게 적응해서 밀크를 마실 수 있음 (타사 상표 언급은 해당 인플 건 사전 승인 전제)
2. **내측 繋ぎ目 없음** — 이음새 없는 구조라 우유 찌꺼기(ミルクのカス)가 안 낌 (내측 보여주는 신과 세트)
3. **내측 目盛り** — 우유 탈 때 정확히 계량 가능
4. **빨대로도 밀크 가능 + 밸브 압력 빼기** — 따뜻한 우유가 샐 것 같으면 **밸브 부분을 수차례 눌러 압력을 빼면 샘 방지** (참고영상=세은 보유)

**타사 대비 부품 수 적음 = 사실 (세은 확정 2026-10-21, 三輪 건)** — 「パーツが少なくてお手入れがラク」 소구 사용 가능. ※10/12 페인포인트 세션의 "부품수 미실측"은 수치 비교표 기준이고, 소구 자체는 세은이 사실 확인함.

**How to apply:**
- 이미지 프롬프트, 릴스 자막, 카탈로그 카피, DM 등 PPSU 스트로머그 특징 언급 시 이 3개만 사용.
- "누수 방지로 외출 시 안심" 같은 뭉뚱그린 표현보다 "아무리 흔들어도 안 샘"처럼 구체 표현 선호.
- 스테인리스(チェリーピーチ 등)와 PPSU는 별개 제품. 혼동 금지.
