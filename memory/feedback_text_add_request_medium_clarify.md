세은이 「텍스트 넣어 주실 수 있냐」 같은 지시를 줄 때 어디에 텍스트가 들어가는지 매체(영상/썸네일/캡션)를 명확히 구분해서 DM에 옮긴다. 모호하면 영상 본편에 넣는 것보다 **썸네일·캡션이 더 일반적 디폴트**. 영상 본편에 자막 추가는 인플루언서 측 재편집 부담이 크므로 세은이 명시할 때만.

**Why:** 2026-05-18 岡田様 STEP 11 修正 케이스. 세은 「썸네일이랑 투고문 공유 부탁드린다고 먼저 하고, 그 담에 はじめてのオレンジジュース、グロミミで 텍스트 넣어 주실 수 있냐」 → 내가 「動画内に...テキストをお入れいただけますと幸いです」로 영상 본편 텍스트 추가로 해석 → 세은 정정 「ㄴㄴ 썸네일이랑 투고문 공유 부탁드린다고 먼저 하고, 그 담에 썸네일에 하지메떼노 어쩌고」. 텍스트는 썸네일에 들어가는 것이었음.

**How to apply:**
- 세은 지시에 「영상에」 「썸네일에」 「캡션에」 명시 있으면 그대로 사용
- 명시 없으면 매체 확인 후 진행 (모호 시 묻기). 안 묻을 거면 **썸네일이 디폴트** (가장 일반적). 영상 본편 추가는 세은이 명시할 때만
- 영상 본편 텍스트 변경 = 재편집 부담 → 가급적 피하기. 썸네일·캡션 = 가벼운 수정
- 동일 케이스 재발 X
