폼(계약정보·재협업·투고완료) 입력을 요청하는 DM엔 **반드시 해당 폼 URL을 본문에 넣는다**. 「下記フォームよりご入力を」만 쓰고 링크를 빼면 인플루언서가 입력할 수 없다.

2026-10-05 坂田 재협업 조건확정 DM에서 "フォームのご入力をお願いできますでしょうか"만 쓰고 폼 링크를 누락 → 세은 강한 교정 「폼 주소를 주지도 않고 어떻게 입력하라고 미친것아」.

**Why:** 표준 STEP3/재협업/STEP12 템플릿엔 이미 링크가 본문에 박혀 있다. 내가 조건 협의 문장을 커스텀으로 쓰면서 템플릿의 링크 줄을 빠뜨린 게 원인. 상대가 "폼 봤다"고 이전에 말했어도, 지금 입력하라는 턴엔 링크를 다시 넣어야 바로 실행 가능.

**How to apply:**
- "폼 입력 부탁" 문구를 쓰는 순간 → 그 줄 바로 아래 폼 URL 동봉 확인.
- 폼 URL 3종: 신규 `...Scy3qvzsR...` / 재협업 `...Sexi5V8uTM...` / 투고완료 `...SdwfSJ2ry...`. [[reference-influencer-form-response-sheets]]
- 완결 기준 = 받는 사람이 그 DM만으로 실행 가능한가 ([[mistakes-20260909-remittance-format-and-completeness]] 계열).
