DM·일정 안내에서 「6月9日(月)」 같이 날짜 + 요일 표기 시, 요일은 반드시 캘린더 검증 후 명시. 자체 추정 X.

**Why:** 2026-06-08 児玉様 6/9 18시 이후 투고 일정 제안 DM에서 「6月9日（月）」 라고 표기. 실제 6/8 = 월요일, 6/9 = 화요일. 시스템 「Today's date is 2026-06-08」 만 받고 요일 미확인 상태에서 자체 추정으로 잘못 표기. 인플 측 「8日은 月曜日로 오늘인데, 明日(火)을 말씀하시는 건지?」 정정 요청 → 사과 + 새 일정 제안 (10日 水曜日) 필요.

**How to apply:**
- 날짜 + 요일 동시 표기 시 요일은 자체 추정 X
- 시스템 메시지 「Today's date」 만 받은 경우 → `date +%A` 등 캘린더 도구로 요일 확인
- 또는 메모리·세션 컨텍스트에서 명시 요일 단서 활용
- 모호 시 요일 표기 생략 「6月9日にて」 OK. 「6月9日（火）」 같이 단정 X
