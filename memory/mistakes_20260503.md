## 호칭 룰 4단 위반 (마리아 건)

마리아 본명 「岡田真里亜」 받은 후 호칭 4번 연속 틀림:
1. 풀네임 「岡田真里亜」 본문 노출 → 1차 짜증 ("도구 출력에 풀네임 그대로")
2. 닉네임 「まりあ様」 사용 → 2차 짜증 ("이름으로 부르라고")
3. 이름 「真里亜様」 사용 → 3차 짜증 ("아니 돌았니? 성으로 불러야지")
4. 정답 「岡田様」 → OK

**교훈:**
- 일본 비즈니스 호칭 = 성씨+様가 표준
- 본명 풀네임 받으면 자동으로 성씨 추출 → 호칭 변경
- 닉네임/이름/풀네임 호칭은 친밀 관계에서만, 비즈니스 X
- 인플루언서 메모리 파일 호칭 필드도 본명 받은 즉시 「{성}様」로 갱신

## 가이드라인 카테고리 룰 1턴 만에 재위반

세은 지시: "DM에 카테고리 명시 X, 그냥 가이드라인이라고만". 메모리 룰 저장 후 바로 다음 답변에서 「カテゴリーにつきましても〜」라고 또 「カテゴリー」 단어 사용. 인플루언서가 「カテゴリー」 단어 먼저 써서 따라 씀.

**교훈:**
- 룰 받은 직후 직전·차후 답변 전체 점검 필수
- 인플루언서가 먼저 사용한 단어라도 우리 답변에서는 치환 (「ご撮影の方向性」/「촬영 방향」)

## 복붙 형태 3번 만에 못 맞춤 (릴스 번역)

세은 "내가 바로 복붙할 수 있는 형태로" 요청에 대해:
1. 슬라이드별 일본어만 묶음 → "한줄한줄 해야 될 거 아니야"
2. 영어/일본어 한 줄씩 짝지어 코드블럭 안에 → "한줄한줄 복붙할 수 있게 만들라고 샤갈"
3. 영어 라벨 + 일본어 단일 코드블럭 → OK

**교훈:**
- "복붙" = 코드블럭 hover 시 복사 버튼 (VSCode 환경)
- 한 줄짜리 코드블럭 = 한 줄 복붙
- 처음부터 단일 코드블럭 형태로 제시했어야 함
