# 유상 마무리 DM 末尾 두 줄 패턴

유상 인플루언서 STEP 12 마무리 DM (자료 송부 알림 → 全完了 통합) 末尾는 **두 줄 묶음**:

```
報酬の¥XX,XXX（税込）につきましては、本日中にお振込みさせていただきます。
お振込みが完了次第、改めてご連絡いたしますので、今しばらくお待ちくださいませ🌷
```

**Why:** 2026-05-29 星野様 STEP 12 DM③ 초안에서 「本日中にお振込み」 1줄만 박고 「送金 완료 후 연락」 줄 빠뜨려서 강한 교정 받음 (「아 하나하나 말해줘야 되나 진짜 ;;」). 기존 메모리 룰 `feedback_after_docuseal_send_step65_dm.md` 계열의 「본일 송금 1줄 통합」 표현이 모호해서 실제 운영 패턴(두 줄)을 명확하게 박지 못함.

**How to apply:**
- 유상 STEP 12 全完了 마무리 DM 작성 시 末尾에 반드시 두 줄 묶음:
  1. 「報酬の¥XX,XXX（税込）につきましては、本日中にお振込みさせていただきます。」
  2. 「お振込みが完了次第、改めてご連絡いたしますので、今しばらくお待ちくださいませ🌷」
- 한 줄로 합치지 마 (「本日中にお振込みさせていただき、完了次第ご連絡」 식으로 압축 X)
- 송금 완료 통보는 별도 STEP (이후 실제 송금 후 별도 DM)
- 무상 인플루언서는 두 줄 자체 X
