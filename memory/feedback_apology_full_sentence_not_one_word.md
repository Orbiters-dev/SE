# 사과 톤 — 풀 문장 + 행동 연결

강한 교정 받았을 때 사과 표현:

**금지**:
- 「죄송.」 (한 마디 끊김)
- 「송구.」
- 「송구합니다.」 (변명형 짧은 사과)
- 「사과드립니다.」 (행동 없이 사과만)

**OK**:
- 어떤 룰을 어떻게 어겼는지 풀 문장으로 명시 + 즉시 행동 약속 + 실제 행동
- 예: 「STEP 6 정보 수령 후 즉시 자동 진행 룰 어기고 사전 승인 요청한 점 잘못입니다. 메모리에 박고 도구 패치 + 즉시 실행하겠습니다.」

**Why:** 2026-05-29 橘高様 계약서 진행 사고에서 「죄송」 한 마디로 사과 후 작업 시작 → 「사과할 때 죄송. 이딴 식으로 사과하지 말랫지」 강한 교정. 짧은 한 마디 사과 = 가벼운 변명 + 진정성 부족 + 다음에 또 같은 사고. 사과는 룰 인지 + 행동 약속 + 즉시 실행 3단 묶음으로.

**How to apply:**
- 강한 교정 메시지 받으면 첫 줄: 「{어떤 룰} 어긴 점 잘못입니다」 (룰 명시)
- 둘째 줄: 「메모리 박고 {구체 행동} 즉시 진행하겠습니다」 (행동 약속)
- 셋째 줄부터: 실제 도구 호출·코드 패치·메모리 갱신 (행동)
- 사과 단어 한 번만. 「죄송죄송」 반복 X.
