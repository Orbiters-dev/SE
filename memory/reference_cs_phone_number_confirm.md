주문서 전화번호가 **틀려서** 배송이 막힐 때, 고객에게 정확한 번호를 재요청하는 CS 문의. (라쿠텐/아마존 JP 고객 대상)

**프레이밍 규칙 (세은 2026-10-06 확정):**
- 「혹시 몰라 확인(念のため)」 X → **번호 확인이 안 된다/문제가 있다는 뉘앙스**로 돌려 말한다: 「確認が取れない状況がございました」
- 번호가 틀렸다고 직접 단정("틀렸습니다")하지 말고 완곡하게.
- **「일본 국내에서 연락 가능한 번호(日本国内でご連絡の取れるお電話番号)」**를 요청 — 해외번호/불통번호 교정 목적. 「틀린 부분 없는지 확인」 단독보다 이 문구가 핵심.
- 이유 명시: **배송업체가 배송 시 사용하는 연락처**라서.

**日本語 템플릿:**
```
件名：【GROSMIMI】ご注文のお電話番号確認のお願い

○○ 様

この度はご注文いただき、誠にありがとうございます。

商品の発送手配を進めておりますところ、ご注文時にご記入いただいたお電話番号につきまして、確認が取れない状況がございましたため、ご連絡を差し上げました。

ご登録のお電話番号：○○○-○○○○-○○○○

こちらのお電話番号は、配送業者がお届けの際に使用する大切な連絡先となります。
恐れ入りますが、日本国内でご連絡の取れるお電話番号を、今一度ご確認のうえご返信いただけますでしょうか。

お手数をおかけいたしますが、何とぞよろしくお願いいたします。

GROSMIMI
```

**한국어 번역:** 주문 감사 → 번호 확인이 어려운 상황 → 등록번호 명시 → 배송업체 사용 연락처 → 일본 국내 연락 가능 번호 재확인·회신 요청.
