기존 PNG 그래픽(라쿠텐 리뷰 캠페인 かんたん3ステップ 등)을 부분 수정할 때 PIL로 처리하는 3원칙. 2026-09-11 세은 교정 2회("아랫부분 이상하잖아" → "아직도 이상하다") 후 확립.

**1) 텍스트 편집 = 폰트 재렌더 X, 원본 글자 픽셀 재사용.**
- 일본어 폰트 매칭은 거의 실패 → 이질감. 대신 이미 렌더된 글자를 `crop` 해서 `paste`.
- 예: 2줄로 접힌 항목을 한 줄로 합치기 = 2번째 줄 글자를 crop → 1번째 줄 「、」 뒤에 paste(같은 폰트/색이므로 완벽 일치). 아래 항목들은 블록 통째로 crop 후 위로 shift(원본 렌더 보존, 폰트 무관).
- 빈 자리 채우기 색은 실제 픽셀 샘플로(이 카드 흰색 = `(254,255,250)`, 순백 아님).

**2) clear/paste 사각형은 요소의 실제 경계 안으로 — 둥근 모서리 overpaint 금지.**
- 교정1 원인: clear 사각형 x를 2360까지 잡음. 카드 흰영역은 x**89–2323**뿐이고 y1710부터 모서리가 둥글게 좁아지는데, 2360까지 흰색을 칠해 **모서리 밖 노란 영역에 흰 돌기** + 둥근 모서리를 네모로 뭉갬.
- 대응: 편집 전 **행별로 흰영역 x범위를 실측**(numpy mask, `white x (min,max)`)하고, 그 안쪽으로만(예 x 130–2300, y ≤1720) 작업. 둥근 모서리 시작 y(여기선 1710~)부터는 절대 침범 X.

**3) 여백/배경 확장 = 그라데이션 포함 스트립 타일링 금지(줄무늬 원인).**
- 교정2 원인: 하단 여백 14px를 핑퐁 타일링. 그 14px엔 카드 밑 halo 그라데이션(B 221→182)이 들어있어 **14px마다 반복 = 가로 줄무늬**.
- 랜덤 행 선택+수평 roll도 실패 — 세로 연속성 깨져 각 행이 가로 줄로 뜸.
- 정답: **매끈한 텍스처 소스(상단 여백 94px 등)를 42px 통짜로 crop → 타깃 배경 평균색으로 채널별 shift(delta = bottom_mean − top_mean)** 후 붙임. 실제 종이 그레인 유지·반복 없음·이음새 안 보임.
- 배경은 균일해 보여도 halo/세로 그라데이션 있을 수 있음 → 확장은 **안정 배경색(그라데이션 끝난 행)** 기준으로.

산출 스크립트: `.tmp/fix_hitsudoku.py`. 검증은 항상 모서리 crop 확대 + full-width 이음새 crop 육안 확인. 파일명 한글은 bash `-c` 인코딩 깨짐 → Write로 `.py` 파일화(UTF-8) 후 python 실행.
