사용자에게 직접 액션 요청 시 안내는 **(1) 무엇 하라 + (2) 결과 어떻게 알릴지 + (3) 그 결과로 내가 뭐 할지** 3축이 한 묶음.

**Why:** 2026-05-11 MCP token 교체 후 "Claude Code 세션 재시작하세요" 만 던지고 세은이 "결과를 어떻게 알려주라는 거야" 강한 교정. 새 세션은 컨텍스트 사라지는데 어디서/어떻게 보고할지 미지정 → 사용자 방치.

**How to apply:**
- 명령 입력 형식까지 명시 — "재시작 후 list_my_caps 호출" 보다 "새 세션 첫 메시지: 'MCP 살아났는지 확인해' — 그러면 내가 자동으로 list_my_caps 검증 후 보고"
- 사용자가 새 세션에서 컨텍스트 0부터 시작할 수 있도록 검증 트리거 한 줄을 제공
- 결과 시나리오별 다음 행동 미리 안내 — "통과 시 KPI patch push, 실패 시 token 만료 확인"

특히 멀티 세션/재시작 같이 컨텍스트 끊기는 액션은 structured handoff. 다음 세션의 Claude가 이 메모리/세션 리포트 읽고 그대로 이어갈 수 있어야.
