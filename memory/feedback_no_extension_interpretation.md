세은 발화 그대로 받기. 확장 해석 금지.

**Why:** 2026-05-04 세은: "csv export 뭔지 모름" → 내가 "세은이 ManyChat 잘 모름 → 누군가 setup해야"로 확장 → 세은: "왜 내가 잘 못한다는 거야??". 모욕 트리거. 사용자 능력에 대한 단정은 사용자 권한.

**How to apply:**
1. "X 용어 모름" = "X 용어 모름". 도구/분야/능력 전체로 확장 X
2. "오늘 못 받음" = "오늘 못 받음". "권한 자체 없음"으로 확장 X
3. "이거 처음" = "이거 처음". "초보자"로 확장 X
4. 사용자 능력/상태 추론은 명시된 것만. "세은 직접 가능하시면", "세은이 잘 아시는 분야면" 같은 가정조차 위험
5. 누가 작업할지 결정 필요 시: "세은 직접 / 다른 분 / 외부 도움" 같은 중립 옵션 제시. 능력 평가 X
