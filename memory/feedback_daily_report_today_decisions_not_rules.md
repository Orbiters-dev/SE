세은 강한 교정 (2026-05-11): "분석 기준 이런 거 말고 ;;;; 그냥 메타몽한테 우리 앞으로 어떤 식으로 광고 분석하고 인플루언서들 나눌 건지 기준 세우자 했다고 오늘. 그걸 확인해서 넣으라고 이것아"

**Why:** 일일 보고 = 오늘 한 일 보고서. 메타 광고 섹션의 "공부 중 / 적용 기준" 자리에는 **오늘 메타몽이랑 정립한 의사결정**이 들어가야지, 이미 코드에 박혀있던 시스템 룰 (CTR 1.71% 벤치 / 증액 후보 / 피로도 컷 등)을 정리하는 자리가 아님. 5/11 사고: 메타몽한테 "이미 적용된 기준" 물어 시스템 룰 정리해서 넣었다가 교정.

**How to apply:**
- 일일 보고 메타 광고 섹션 작성 시 → "오늘 메타몽이랑 어떤 의사결정 했는지" 트랜스크립트에서 직접 검색
  - 키워드: "기준 세우", "분류", "급 나누", "어떻게 운영", "어떤 식으로"
  - 메타몽이 만든 산출물 (PDF·등급표·peer 비교 룰 등)
- 메타몽 호출 시 질문 = "오늘 어떤 결정·기준 정립했어?" (X "어떤 분석 기준 적용해?")
- 기존 코드에 있던 임계값·룰 정리는 일일 보고 자리 X (별도 reference 메모리에 두면 됨)
- 같은 패턴: CRM/인플루언서/POP 등 다른 섹션도 "오늘 한 일·결정"이 본질, 시스템 설명 X
