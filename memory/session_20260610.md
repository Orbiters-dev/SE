## 단위 통일 + 등급 표정 (6/10 오후 추가 5)

- 숫자 단위 (세은 지시 v2 최종): **개수(view·노출·LPV 등)만 K/M, 금액(₩)은 풀 자릿수**. fmtCompact는 fmtNum(개수)·fmtViews·fmtFollowers만 경유, fmtWon/fmtKrw/fmtRate는 toLocaleString 풀 표기. "만" 표기는 폐기. (처음에 금액까지 K/M으로 갔다가 정정받음)

## 광고 탭 종합 BEST/WORST + 기준 표기 (6/10 오후 추가 8)

- `compositeBestWorst` (meta-aggregations.ts): 노출 ≥200 게이트 (meta_jp_daily 동일) · 종합점수 = 풀 percentile 가중합 **CPLPV 50% + CTR 30% + CPC 20%** (LPV 효율 1차 축 룰) · WORST는 BEST 제외 후 선정 (메일과 동일 dedup) · n=3 (풀 작으면 자동 축소)
- 광고 탭 최상단 카드: BEST/WORST 각 3개 — 종합점수 + CPLPV·CTR·CPC·Spend 한 줄 + 등급 뱃지 + 상세 링크. 기준 문구 명시
- 기존 CTR/CPC/CPLPV 카드에도 기준 한 줄 ("7일 spend ≥ ₩1K 중 상/하위 5") 추가
