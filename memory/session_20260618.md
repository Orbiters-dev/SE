### 핵심 결정 근거 (수치)
- **PPSU 증액 근거** = 7d Proven 성과 실측: PPSU CPLPV ₩109 / CTR 10.43% / CPC ₩71 **vs** Stainless CPLPV ₩119 / CTR 7.67% / CPC ₩95. **PPSU가 전 지표 우위인데 예산은 절반(55K vs 103K) = 과소투자** → 증액이 정답. (대칭 맞추기가 목적 X, 효율 근거)
- **PPSU 증액 경로**: ₩55K → 65K → 77K → 91K → 93K, **19%씩 2~3일 간격**(learning reset 회피). 각 스텝 **CPLPV ₩135 넘으면 정지**(스케일 한계).
- **Testing ad set당 ₩8,000 고정**: 7d Testing ad-level CPLPV median ₩127 기준 ₩8,000×3일 = D+3 LPV 189 (학습 임계 50의 3.8배) → 학습 충분 검증. 초과 예산은 √n 체감이라 헛돈 → 같은 돈이면 소재 개수↑(발굴 throughput)가 이득 = **개수 우선**. 단 가용 소재 13개 미만이면 차액은 Proven으로(억지 증액 X).
