세은 교정 (2026-09-10): "이 리포트에 위클리 광고비 이런 걸 적으라는 게 아니라, 내가 일주일동안 한 일들 진척사항을 적으라고."

**Why:** 광고 성과 수치는 이미 리포트 본문(총괄·채널별)에 있음. "위클리 정리"는 별개로 **그 주 업무 진척**(리치아웃·계약·CRM·IG/트위터 기획·제품/운영 등)을 정리하는 섹션.

**How to apply:**
- 정본 소스 = **노션 일별 업무일지** (일자별 "YYYY-MM-DD (요일)" 페이지가 실제 기록분, "업무일지" 접미 페이지는 전일 생성 템플릿). 근무일(월~금, 주말 제외)만.
- 카테고리 예: 인플루언서(리치아웃 N명·첫DM답변·계약서 수령·투고 스케줄), CRM 발굴(키워드 재설정·발굴 수), IG/트위터 기획, 제품/운영(라벨 등), 기타(매출보고).
- 세션 메모리(Claude 세션)도 보조 근거지만 정본은 세은의 노션 업무일지.
- 집계 윈도우는 [[weekly-report-효율-집계-기간-전-주-목-0000-그-주-수-2359]] (목→수)와 동일.
