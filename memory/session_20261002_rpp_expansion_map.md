- **라쿠텐 수요 API 재발견** = 이 세션 최대 성과. 라쿠텐은 몰 전체 검색량 비공개지만 RMS RPP가 `recommendationRankedKeywords`(검색량랭크)+`recommendationCpc`(目安 POST+XSRF)로 신호 제공. 예전 GET API 죽어서 네트워크 추적으로 새 POST 엔드포인트 발견. 정본 [[reference_rakuten_rpp_demand_signals_api]].

## 세은 교정 (지표 정의 집요 검증 → [[feedback_report_reader_friendly_metrics]])
