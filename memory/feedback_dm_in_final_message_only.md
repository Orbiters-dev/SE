DM 초안(코드블록+번역)은 **반드시 턴의 최종 메시지**에 넣는다. 하네스 PASS 후 DM을 먼저 출력하고 그 뒤에 메모리 갱신 도구를 돌리면, 최종 메시지가 「메모리 업데이트 완료했어요」 따위가 되어 세은 화면에서 DM이 묻힌다.

**Why:** 2026-10-08 같은 날 2회 — 早乙女 마무리 DM(세은 「장난하니? 발송할 거 안 줬잖아」), 馬場 영상승인 DM(세은 「이거는 왜 디엠 안 줘」). 둘 다 DM을 중간 텍스트로 출력 → 뒤에 Edit(메모리) 호출 → 마지막 메시지에 DM 없음.
**재발 2026-10-14:** 片平 완성본 OK DM — DM을 먼저 출력하고 뒤에 메모리 Edit 2회+요약을 붙임 → 세은 「이거 초안 왜 안 줘」(DM을 못 봄). 같은 턴 濵·加藤·小野 건도 동일 순서 위반이었음.
**재발 2026-10-20 (변형):** 茂渡 폼확인 DM — 초안 Write까지만 하고 하네스·DM 출력 없이 **턴 자체를 종료** → 세은 「왜 멈췄어 계속해」. 중간 배치 위반의 극단형: 초안 Write 후에는 하네스→DM 출력까지 한 턴에 반드시 완주. Write가 턴의 마지막 도구 호출이면 그 턴은 미완성.

**How to apply:** 순서 고정 = ①메모리 확인 ②초안 Write ③하네스 ④메모리 갱신(Edit/Write) ⑤**최종 메시지에 DM 코드블록+한국어 번역+비고**. 도구 호출은 전부 DM 출력보다 앞에. 메모리 갱신을 뒤로 미루는 한이 있어도 DM은 마지막에.
