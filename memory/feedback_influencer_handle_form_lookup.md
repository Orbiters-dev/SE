2026-10-01 강한 교정: yun.mamalog 「フォームの送信が完了しました。ご確認よろしく」 알림 → 내가 폼 종류(STEP3 계약정보 vs STEP12 투고완료)와 폼값을 세은에게 물음 → 세은 「찾아보면 되잖아 장난하나 일부러 핸들로 줬구만」.

**Why:** 세은이 핸들(yun.mamalog)을 준 것 자체가 "폼 응답 시트에서 이 핸들로 찾아 계약서 진행하라"는 지시. 폼 종류·폼값은 내가 시트 조회로 직접 파악 가능한 정보 → 묻는 순간 "직접 파악 가능한 건 묻지 마" 위반. (앞서 のん様 때 핸들 몰라 물은 건 정당했지만, 핸들을 준 뒤엔 조회가 답.)

**How to apply:**
- 인플루언서 폼 제출 알림 + 핸들 수령 → 그 턴에 **폼 응답 시트(`1Gd8JrWm...`, 「기본정보」 탭)에서 핸들로 행 조회** → 풀네임·메일·월령·제품 추출 → DM_CHECKLIST 2(계약서 SOP 자동) 실행. [[reference-influencer-form-response-sheets]]
- 재협업이면 재협업 폼 응답(별도) 확인.
- 폼 종류 모호해도 문맥(투고 언급 없음 + 「ご確認よろしく」 = STEP3 계약정보 폼)으로 판단 후 조회. 조회 결과가 문맥과 맞으면 진행.
- 세은이 핸들·링크를 "일부러" 주면 = 그걸로 직접 조사하라는 신호. 묻기 전에 조회부터.
