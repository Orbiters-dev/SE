DM template (dm-templates, FAQ 등 운영자 입력 콘텐츠) 작업 시 **본문/문구를 사용자한테 요청하지 마**.

**Why:** 2026-05-11 dm-templates 등록 시 "name / region / outreach_type / body 주세요" 라고 세은한테 요청 → 세은 강한 교정 "dm template을 달라고??". 본문은 세은이 작성하는 영역 — 운영 콘텐츠 그 자체. 내가 본문 받아서 내가 등록하면 누가 콘텐츠 owner인지 흐려짐. 본문은 세은 손으로.

**How to apply:**
- 차단된 채널을 풀어주는 게 내 역할 — UI 권한 차단, backend API 인증, 일괄 import 파이프라인
- 본문은 세은이 갖고 있는 workflow/SOP에서 추출하거나 세은이 직접 UI 입력
- "어떤 본문 넣을지" 물으면 안 됨. "어떤 형태로 import할지 (workflow 파싱 / CSV / 수동)" 까진 OK
- 본문 자체가 누락된 상태라면 등록 작업 자체 보류 (UI 차단 풀기 우선)

dm 답장 초안 (인플루언서 응대) 작성은 별개 — 그건 SOP 기반 작성이 내 역할.
