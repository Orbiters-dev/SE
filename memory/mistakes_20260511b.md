# 2026-05-11 (월) — 인플루언서 DM 처리 강한 교정 5건

## 1. Tenu様 STEP 5 — 사이즈·컬러 옵션 본문 나열
- 작성: 「サイズは200ml / 300mlの2サイズ、カラーはホワイト / チャコール / ピンク / スカイブルーの4色からお選びいただけます」
- 세은: 「사이즈랑 컬러 줄줄 늘어놓지 말랬지 내가」
- 룰: 워크플로우 STEP 5 원본 「ご希望のサイズ・カラーがございましたら」 한 줄. 사이즈·컬러는 인플루언서가 링크에서 직접 확인
- 신규 메모리: `feedback_no_size_color_enumeration.md`

## 2. Tenu様 일본어 부자연 표현 — 「心強く拝見」 / 「든든하다」
- 세은: 「든든하다 이딴 거 ㄴ」
- 일본어로 어색하게 직역된 표현. 본인 메시지에 인용·승낙 표현으로 자연스럽게 받기

## 3. 児玉様 STEP — 페이스·기간 요청에 일방적 통보
- 본인: 「制作中です。1週間ほどお待ちいただいてもよろしいでしょうか?」
- 작성: 「20日頃を予定しておりますので、それまでに下書きをご共有いただけますと」
- 세은: 「싸가지 없게 말하지 말고, 일주일 정도 시간 가지고 제작해 주시고 ~~ 이때까지는 제출 부탁드린다 이렇게 정중하게」
- 룰: 본인 요청을 먼저 받아주기 (「1週間ごゆっくりお時間取って構いません」) + 마감은 「誠に恐れ入りますが○日頃まで」 정중하게
- 신규 메모리: `feedback_respond_to_pace_request.md`

## 4. 町谷様 — 완료 응답 받고 단순 ACK으로 끝
- 본인: 「共同投稿させていただきました」
- 작성: 「確認させていただきました」 + 굽신 마무리만
- 세은: 「ㅡㅡ 다음 단계로 넘어가야 될 거 아니야」
- 룰: 완료 시그널 수령 시 워크플로우 다음 STEP을 같은 DM에 묶음 (投稿 완료 → STEP 12 광고코드+원본영상)
- 신규 메모리: `feedback_ack_plus_next_step.md`

## 5. 岡田様 — 외부 정보 본문에 자리표시자
- 작성: 「【返送先住所】〒[주소 자리] [주소 자리]」
- 세은: 「주소는 내가 따로 첨부할 테니까 너는 그냥 형식만 쓰면 돼 제발」
- 룰: 세은이 「내가 첨부할게」 명시한 정보는 본문에 자리표시자 X. 「下記の住所」 참조 표현으로 마무리. 정보는 세은이 별도 메시지
- 신규 메모리: `feedback_dont_insert_placeholder_for_external_info.md`

## 종합

5건 모두 「본인 응대 + 워크플로우 정형 + 표현 자연스러움」 기본기 위반. 매번 같은 패턴 반복:
- 본인 요청(페이스·시간)을 무시하고 우리 결정 통보
- 본인 완료 응답에 단순 감사로 끝내고 다음 STEP 누락
- 워크플로우 원본 템플릿 변형 (옵션 나열·자리표시자 추가)
- 일본어 직역 표현 (「心強く」)

DM 작성 전 워크플로우 원본 + 기존 feedback 메모리 재조회 강제.
