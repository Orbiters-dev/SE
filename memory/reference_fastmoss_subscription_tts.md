# FastMoss 구독 상태 + 용도 정본 (2026-10-02 틱톡이 확인)

## 틱톡용? 틱톡샵용? → **틱톡샵(TikTok Shop / TTS) 세일즈 데이터 분석 툴**
- 광고 집행(GMV Max·Spark Ads) 툴 **아님**. 샵에서 **뭐가 얼마 팔리나·어떤 크리에이터가 GMV 내나** 들여다보는 리서치/인텔리전스.
- 핵심 데이터 = 상품 **Units Sold·전환율·가격대**, 크리에이터 **GMV·판매량**, 바이럴 영상·샵별 GMV. (영상 조회수 아님)

## 구독 = 활성 (세은 2026-10-02 "구독했었잖아")
- 무료는 상위 5행만 → 구독으로 **전체 유료 풀 접근 열림**.
- 이전엔 "확인 못 함"이던 **JP 베이비 카테고리 상품 랭킹 + JP 유아 크리에이터 전수**(category=Baby 필터는 유료 플랜)를 이제 뽑을 수 있음.
- ⚠️ 로그인 계정 미확인(세은에게 받아야 접속). Seller Center 계정(onzenna/hello@zezebaebae.com)과 별개일 수 있음.

## 쓰는 법 (우리 용도)
| 탭 | 설정 | 활용 |
|---|---|---|
| Products(상품 랭킹) | region=JP → category Baby | 경쟁 베이비 상품 Units Sold·승자 패턴 |
| Creators | JP 유아 카테고리 | **육아맘 틱톡 침투도 검증** = JP 틱톡샵 진출 최대 병목 |
| Videos/Shops | JP | 승자 소재 각·어필리에이트 타겟 발굴 |

- JP 지원 확정(국가 셀렉터 Japan 실재·`?region=JP`). 교차검증 툴 = Kalodata·EchoTik(셋 다 JP).

## 리스크
- FastMoss 수치 = 틱톡샵 **공식 아닌 모델 추정**. 절대 GMV로 채산성 계산 금지 → **상대 랭킹/추세**로만. (근거 2026-08-31 실측, 틱톡이 SKILL 실측 섹션)
