# 부탁은 의문문 정중형

인플루언서에게 무언가 해달라고 부탁할 때 표현:

**금지 (평서문)**:
- 「ご制作いただけますと幸いです」 (제작해주시면 좋겠습니다)
- 「お送りいただけますと幸いです」 (보내주시면 좋겠습니다)
- 「ご対応いただけますと幸いです」 (대응해주시면 좋겠습니다)

**OK (의문문 정중형)**:
- 「ご制作いただくことは可能でしょうか？🙇‍♀️」
- 「お送りいただけますでしょうか？🙇‍♀️」
- 「ご対応いただけますでしょうか？🙇‍♀️」

**Why:** 2026-05-29 asahi様 영상 컨셉 부탁 시 末尾에 「Vlog風の自然な日常の中に、弊社商品が溶け込むような形でご制作いただけますと幸いです🌿」 평서문으로 박았다가 「제작해주실 수 있겠냐고 물어보라니까 ㅡㅡ 정중하게」 강한 교정. 평서문은 일방적 통보 + 강요 톤. 의문문은 인플 측 거절 여지 + 정중 + 협의 톤.

**How to apply:**
- 새로운 요청·추가 부탁 시 末尾 핵심 부탁 의문문으로
- 「~いただけますと幸いです」 다용해도 OK이지만 **핵심 부탁 (수락/거절 선택권 줘야 할 사항)**은 의문문
- 단순 정보 안내 (「ご確認のほどよろしくお願いいたします」 등)는 평서문 OK
- 의문문 末尾 「🙇‍♀️」 등 정중 이모지 동반
