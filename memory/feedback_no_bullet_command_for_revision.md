영상·하서·썸네일 등 수정 요청을 인플루언서에게 보낼 때, **「・현재 3〜5초 부분은 잘라주세요」 「・30초로 조정해주세요」** 같은 불릿+단정조로 나열하지 않는다. 대신 **한 문단 안에 흐름 있게** 적고, 마지막을 **「この方向でいかがでしょうか？」 「ご対応可能でしょうか？」** 같은 제안+질문 톤으로 마무리한다.

**Why:** 2026-04-29 今西様 케이스. 「具体的な修正点としましては、・現在の3〜5秒部分はカット ・32秒目以降カット ・30秒程度に調整」 식으로 불릿+단정조로 작성 → 세은 「싹아지 없게 말하지 마」 질책. 인플루언서가 영상 만든 사람인데 명령조로 잘라라/조정해라 하면 무례. 우리는 같이 의논하는 입장이지 지시하는 입장 아님.

**OK 예시 (세은 직접 작성한 톤):**
> 빨대 데뷔를 테마로 하기로 하고, 영상도 30초 정도로 줄이기 위해 현재 제품만 비치는 3~5초 부분이나 32초 이후의 부분들은 제외해 주셔도 되고, 전체 30초 정도로 맞추어서 저작권 프리 음악 넣으면 영상이 좀 더 템포 있게 잘 전달될 것 같은데 이런 방향으로 괜찮으실까요

**How to apply:**
- 「具体的な修正点としましては、・~ ・~」 같은 항목 나열 X
- 「~~するために、~~部分などはカットしていただいても問題ございませんので、~~いただけますと、~~かと存じますが、この方向でいかがでしょうか？」 식 한 문단 흐름
- 「カットしてください」 명령조 X → 「カットしていただいても問題ございません」 허용형
- 마무리는 반드시 「いかがでしょうか」 「ご対応可能でしょうか」 형 질문
- STEP 11 「修正あり」 워크플로우 템플릿 그대로 쓰지 말고 흐름형으로 재작성

**2026-10-16 しろ様 재발 (3회차):** 테마 전환 요청(교환 빨대 3포인트)을 「・~」 불릿 3개 + 「構成いただけますと幸いです」 단정조로 작성 → 세은 「해 주시기 바랍니다 라고 하지 말고 이런 테마로 구성해 주시는 게 어떨까요? 이렇게 하라고」. **테마 제안·구성 요청도 수정 요청과 동일 룰** — 포인트 복수여도 한 문단 흐름에 녹이고 「いかがでしょうか」로 마무리.

**2026-10-21 三輪様 뉘앙스 확정 — 금지는 "명령조"지 "항목화"가 아님:** 복수 포인트(4건) 테마 제안을 흐름형 한 문단에 전부 녹였더니 세은 「구구절절 쓰지 말고 **항목화해서 보기 쉽게**」. 정답 형식 = 배경·테마 문장(방침 설명 1줄 포함) → **①②③ 항목 나열** → 「この方向でまとめていただくことは可能でしょうか？」 제안형 마무리. 즉 ①포인트 2개 이하·수정 지적 = 흐름형 ②포인트 3개+ 테마 제안 = 항목화 + 제안형 마무리. 어느 쪽이든 명령조(〜してください 나열)만 금지.

**2026-10-06 井手様 재발:** 수정 2건(①릴스 30-40초 ②蓋のゴムパッキン을 타사 머그와 비교컷 추가)을 「・~」 불릿 2개로 나눔 → 세은 「ㄴㄴ 두 가지 항목으로 나누지 말고, 현재 3-40초 길이를 부탁드리고 있기도 하니 고무패킹 비교를 함께 넣어주는 게 어떠냐 이런 식으로 하라고」. **항목이 복수여도 불릿로 나누지 말 것** — 길이 안내 같은 부수 조건은 메인 요청의 **맥락/전제로 녹여** 한 문장 흐름으로. 복수 요청 = 불릿 유혹 크지만 금지.
