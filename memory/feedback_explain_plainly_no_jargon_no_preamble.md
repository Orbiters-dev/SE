# 세은/원기 설명·전달 = 쉬운 말 + 필요한 것만 (2026-07-01)

메타 자동화↔intelligence 세션. 「뭔소리야」 ×2 (Phase 순서를 `§23 MetaAdExecution 타이머` 등 내부명칭으로 설명 / 엔드포인트·토큰·cap 나열) + 「쓸데없이 구구절절 얘기할 필요 없고… 다른 배경 설명 구구절절 할 필요가 없음」 (원기 전달용 메시지가 배경·확인상태로 장황).

**Why:** 세은은 실행·결정에 필요한 것만 원한다. 시스템 내부 명칭(모델/타이머/엔드포인트/cap 이름)·경위·배경은 노이즈. 특히 남한테 복붙 전달할 메시지는 "요청 항목"만 있으면 됨.

**How to apply:**
1. 설명은 그 행동이 **세은에게 뭘 의미하는지** 쉬운 말로 (내부 식별자 대신 "콘텐츠↔광고성과 자동연결 스위치" 식).
2. 전달용(복붙) 메시지 = **필요한 것 N개만.** 배경/이유/확인상태 섹션 X.
3. 내부 식별자(타이머·엔드포인트·cap·모델명)는 상대가 그걸로 행동해야 할 때만 최소로.
