인플루언서가 자료(원본 영상/광고코드/캡션 등) 송부 알림을 보내오면, 「こちらで確認させていただきますね」 류의 **별도 ack DM 보내지 말 것**. 세은이 별다른 코멘트 없이 진행시키면 = 확인 완료 = OK 라는 뜻이므로, **全完了 마무리 + 송금 약속(유상)을 한 번에 통합한 DM** 발송한다.

**Why:** 2026-05-21 村井様 ギガファイル便 원본 송부 알림 후속. 「ご送付ありがとうございます。こちらで確認させていただきますね。何かございましたら改めてご連絡」 옵션 A 답신 제시 + 「영상 검증 OK면 다음 DM에서 全完了 + 입금」 분리 진행을 제안. 세은 명시: "ㅇㅇ 확인했고 확인 안 됐으면 너한테 확인 안 됐다고 말하겠지 내가 너한테 아무말도 안 하는 건 그냥 확인됐다는 뜻이니까 항상 송금 약속까지 함께 붙이면 돼".

**How to apply:**
- 자료 송부 알림(원본 영상/광고코드/캡션·썸네일 등) 답신 = 마무리 단계 통합 DM 1회로 끝낸다 (별도 ack 2회 분리 X)
- 통합 구조 (유상 STEP 12 마무리 패턴):
  ```
  ○○様

  ご連絡ありがとうございます😊
  〜 送付に対する御礼 ＋ 拝受確認 一文 〜

  この度は素敵なコラボレーションをありがとうございました。
  今後もまた良いご縁がございましたら、ぜひよろしくお願いいたします😊

  なお、ご報酬につきましては本日中にお振込みさせていただきますので、何卒よろしくお願いいたします🙇‍♀️

  GROSMIMI JAPAN
  ```
- 무상(gifting)도 동일 — 단 입금 줄 X
- 세은이 자료에 문제 있어 정정 지시하면 = 그때 별도 답신. 침묵 시 즉시 통합 마무리
- DM_CHECKLIST 룰 6번과 동일 흐름. workflow `STEP 12 DM③ 全完了` 베이스에 통합
