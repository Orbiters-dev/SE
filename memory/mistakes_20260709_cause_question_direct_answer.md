# 오답노트 2026-07-09 — 「왜 안 되냐」 질문 = 원인 한 줄 단정 먼저

## 사고
JP BSR 시트 K/L(Parent Level Sales/Revenue) 공란 이유를 세은이 물음.
1차 답변: 의미 설명 + 「export 컬럼 구성 차이로 보임」 + 「JP Xray에 컬럼 있는지 세은 화면에서 확인해달라」로 마무리.
→ 이틀 뒤 「아니 근데 K랑 L 칼럼 안 채워지는 이유 뭐냐고 묻잖아」 재질문 받음.

2차에서야 정답 구조로 답함: **①원인 단정 한 줄(소스인 JP CSV에 컬럼 자체가 없음 — 실측) ②왜 내가 못 채우는지(H10 추정값이라 export가 유일 소스 + 크레덴셜 전무 전수확인) ③해결책 1개(재export)**.

## 룰
- 「왜 안 되냐/왜 비었냐」 = 원인 질문. 답변 1문장째가 **검증된 원인 단정**이어야 함. 배경 설명·가능성 나열·상대방 확인 요청으로 시작하면 질문이 해소 안 된 것.
- 원인 체인은 끝까지: 「소스에 없어서」로 끝내지 말고 「그 값은 어디서도 못 구하는 값인가(대체 경로 전수 확인)」까지 닫고 답할 것. 대체 경로 확인 전이면 그 확인부터 하고 답변.
