# 외부 심사 제출물 = 내용 정합성 먼저, 기술 조건은 그다음

TikTok Marketing API 재신청에서 Company Website로 onzenna.com(US 브랜드 사이트)을 제안 →
세은 교정: 신청 주체가 "Grosmimi JP Ads"인데 그걸 설명하지 않는 도메인을 낼 수는 없다.

**Why:** 나는 Bytespider 통과(기술 실측)라는 단일 조건으로 도메인을 골랐고, 심사자가
그 필드를 "신청 회사/사업을 설명하는 창"으로 본다는 당연한 관점을 빠뜨렸다.
기술적으로 통과해도 내용이 안 맞으면 다른 사유로 반려되거나 신뢰를 깎는다.

**How to apply:** 외부 플랫폼 심사(API 신청·앱 리뷰·광고 계정 인증 등)에 넣는 모든 필드는
① 먼저 "심사자가 이 필드로 뭘 판단하는가"에 맞는 값인지 확인 → ② 그 안에서 기술 조건
(접근성·보안·차단)을 통과하는 걸 고른다. 순서 역전 금지. 후보가 정합성에서 전멸이면
"정합한 도메인을 고치는" 쪽(차단 해제 등)이 정답이지 "통과하는 아무 도메인"이 아니다.
