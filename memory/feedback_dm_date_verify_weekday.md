7/6 金原様 투고일정 DM에 「7月8日(火)」로 표기 → 세은 "7/8 수요일이다" + Harness Gemini FACTUAL FAIL. 2026-07-08은 수요일(水).

**Why:** 세은이 "7/8"만 말했고 요일은 안 줬는데 내가 (火)를 임의로 붙임 + 계산 안 함. 오늘(7/6)이 월요일이면 7/8=수요일인데 확인 없이 화요일로 적음.

**How to apply:**
- **일본어 DM에 「N月N日(요일)」 병기할 때, 요일은 반드시 실제 날짜로 계산해 검증.** date 계산 확실치 않으면 요일 괄호 자체를 빼고 날짜만 (「7月8日18時以降」). のぴ様 케이스는 요일 생략으로 리스크 회피함.
- 세은이 요일 없이 날짜만 줬으면 내가 요일 붙이지 말거나, 붙이려면 계산 검증 후.
- Harness Gemini FACTUAL axis가 날짜-요일 불일치를 잡아줌 → PASS 뜰 때까지 재확인.
- 참고: 2026-07-06 월 / 07 화 / 08 수.

## 재발 2026-10-01 (加藤様)
加藤様 투고일 「10月6日(月)」로 표기 → Harness Gemini FACTUAL FAIL → 실제 (火)로 수정. 10/4=일 기준 역산(10/5 월·10/6 화·10/7 수·10/9 금) 안 하고 임의로 (月) 붙임. **날짜 받으면 기준 요일(세은이 준 「4일 일요일」 등)에서 역산해 요일 검증 후 기입.** Harness Gemini가 또 잡아줌.
