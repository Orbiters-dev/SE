인획이 주간 IG 기획안 엑셀 저장 경로는
`C:\Users\orbit\Desktop\s\세은 기획 자료\인스타그램 기획안\EXCEL\` 이다.
구 경로 `...\요청하신 자료\...` 는 폐기 — 절대 쓰지 마라.

**Why:** 7/2 7월 W1 기획안을 구 경로(요청하신 자료)에 저장 → "한 번 말하면 제대로 저장 안 할래" 강한 교정. SKILL.md 268행이 구 경로였고 그대로 따라감. 세은이 이미 경로 변경 지시한 걸 반영 안 한 상태였음.

**How to apply:** SKILL.md 저장 위치 = `세은 기획 자료`. 기획안 저장 시 이 경로 그대로. 룰 바꾸라 하면 SKILL 코드까지 즉시 동기화 ([[feedback_sync_code_when_memory_rule_changes]]). 세은 지적 = 이미 지시한 것 재위반 신호 → 도구/SKILL 하드코딩값부터 의심.
