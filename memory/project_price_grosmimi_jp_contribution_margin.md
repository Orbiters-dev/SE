## 핵심 방법론 결정 (세은 합의)
- **제품별 분리**: 세금은 HS코드 직접귀속(3924.10 PPSU / 9617.00 스텐), 운임·대행은 CIF비율 배분.
- **환율**: 통관·운송(KRW→JPY)은 청구서 시점 고정(해상 932.42/항공 965.29). COGS(USD→JPY)는 가변 입력셀(C5, 통관시점 159.38) — 셀 하나 바꾸면 전체 재계산.
- **免税/課税 2버전**: LittlefingerUSA는 2026 면세사업자(소비세 신고 X)→2027 과세. 면세=수입소비세 비용포함(개당 ¥205급)·판매세 0 / 과세=관세만·판매세는 판매가×10/110. 수입소비세는 과세사업자면 매출소비세서 공제(仕入税額控除)되어 비용 아님 → 면세라 못 돌려받아 비용.
- **BOSS = 고정비** → 공헌이익서 제외, 아래 "월 고정비"로 분리(월액 ¥3,000).
- **보관료 = 변동비**(재고량 비례) → 공헌이익 포함. 단 현 재고회전 9.1개월(런칭 과잉)은 단가에 안 박음; 지정 SKU의 月金額÷재고(¥12)를 그대로 사용.
- **변동비 = COGS + Logistics + 라쿠텐 + RSL출고 + RSL보관 + (과세)소비세.**
