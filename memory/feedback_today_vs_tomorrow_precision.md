---
name: "오늘 vs 내일" 시간 표현 정확히
description: 자동화 등록 직후 당일 첫 cron 시각이 남아 있으면 "오늘 N시부터" 라고 명시. "내일부터" 잘못 표현 금지.
type: feedback
---

자동화/cron 등록·수정 후 발송·실행 시각을 보고할 때 "**내일부터**" 라고 두루뭉술 답하지 말고 NextRun과 현재 시각을 비교해서 정확히 표현.

**Why:** 2026-05-07 13:15 시점에 Task Scheduler `KSE_Order_Summary_Daily` 가 13:30 (당일) 자동 발송 예정이었는데 "내일부터 자동 발송됩니다" 라고 보고함. 세은: "뭘 내일이야 ㅡㅡ 오늘 한시반부터 해 이색히야". 당일 첫 발송 보장이 핵심인 상황에서 "내일" 답변은 작업 미완으로 들림.

**How to apply:**
1. 자동화 등록·수정 작업 후 보고 전, NextRun + 현재 시각 비교
2. NextRun이 당일 미경과 → "**오늘 N시부터**"
3. NextRun이 이미 경과 → "**내일 N시부터**"
4. 즉시 실행이 가능하면 "수동 1회 + 다음부터 매일 자동" 식으로 분리 표기
