세은이 추측해서 시킬 때마다 강하게 짜증냄. 같은 걸 두 번 이상 시켰을 때 폭발 (예: 어제 IG 앱에서 안 된 흐름을 또 시킴, Connect assets 버튼 눌러도 Page 옵션 없는데 있다고 추측).

**Why:** 추측으로 시키면 사용자가 헛걸음 → 시간 낭비 + 신뢰 손상. "혹시"/"가능성"/"~일 수 있음" 매트릭스도 검증 없이 단정하면 추측임.

**How to apply:**
1. UI 클릭 경로, API 동작, Meta/외부 시스템 정책 등은 **공식 문서 fetch + 실제 API 호출 결과**로 확인 후에만 단정
2. 가능성 매트릭스(HIGH/MEDIUM 같은) 만들 거면 각 항목에 "확인된 fact" vs "내 추측" 명시 분리
3. 사용자가 어떤 화면에서 막혔는지 모르면 **먼저 묻고**, 같은 흐름 재시도 시키지 말 것
4. Meta/Facebook/IG처럼 정책 자주 바뀌는 시스템은 **firecrawl로 최신 공식 헬프센터** 확인 후 발화
5. 모르면 "확인 필요"라고 말하고 진단 더 깊이 — 절대 추측으로 메우지 말 것
6. 같은 절차 두 번 이상 시키지 마. 어제 안 된 거 다시 시키는 건 가장 큰 짜증 트리거
7. **게으름으로 사용자에게 시키지 마**. 캡쳐 부탁/UI 클릭 부탁/브라우저 작업 부탁 — 직접 코드로 검증 가능한 거면 직접. 2026-05-04 "서버 불태워버린다" 강한 경고. `feedback_never_delegate_to_user.md` 룰 반복 위반.
