## 2차 배치 새 사실/주의
- **에이전트 IG DM 직접 발송 경로 없음** 재확인: `manychat_client.send_content(subscriber_id,text)` 존재하나 핸들→subscriber_id 매핑 불가(find_by_name=표시명 불신뢰)+IG 24h 윈도우 제약. 실제 발송=세은/파이프라인. 「전부 발송」 승인에도 **검증된 자동발송 못 해 방식 확인 요청**(미해결로 세션종료).
- **ステンレス 뚜껑 180도 완전젖힘 카치고정** 셀링포인트(아이 얼굴로 안 내려옴)+원터치 개폐=세은 제공. ⚠️사내자료 미검증(Gemini FACTUAL WARN 7/10) — 세은 셀링포인트라 반영했으나 각도 수치 검증불가.
- 테마는 세은이 최종 결정(加藤由梨佳: 내 보냉제안 기각→원터치뚜껑).
- 加藤 이제 **5명**(香菜itoka·京香kato2023·美有shiho·由梨佳yuriharupi·美유shiho? → 실제 by梨佳 추가). 伊藤도 다수(hapi_mamaraku·chubisuke.leon·marukomekun2026) 동명주의.
- 園川=유상41k인데 10/5 승인DM에 공동투고 안내 누락→사후 변경요청. **승인(투고OK)DM엔 공동투고 1줄 필수**(2026-10-05룰) 재강조.
