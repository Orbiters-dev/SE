### 2. 단가 공식 노출 OK / 1.5엔 고정 X (ninaちゃんママ)
- 내가: 「사측 내부 기준 노출 X」 광역 적용 → 단가 공식(1.5엔) 제거 + 「予算規定により」 표현
- 세은: "아니 사내 규정 상 팔로워당 1원으로 산정하고 있다고 하면 돼. 1.5엔은 그냥 내가 대충 산정해 본 거고, 항상 그렇게 할 필요는 없고 역산 적용해서 대충 ㄱㄱ"
