# 사용자가 특정 셀/SKU/값 지정하면 내 정교한 방법으로 덮어쓰지 마

2026-06-18 공헌이익 워크북. 보관료를 세은이 "72171-00000002 여기 있는 애로 계산하면 될 듯"이라고 명시 지정. 그런데 나는 体積×7.5×회전개월, 월총보관료÷전체판매수량(¥108) 같은 "더 정확한" 배분을 계속 제안 → "아니 전체로 나누지 말고 내가 시키는 대로 하라고 임마 ㅡㅡ 72171-00000002 여기에 있는 애로 하라고 이해했어?" 강한 교정.

**Why:** 사용자가 구체적 기준(특정 SKU 행의 金額÷재고 = ¥12)을 줬으면 그건 이미 판단이 끝난 지시다. 내가 방법론적으로 더 낫다고 생각하는 배분(전체분배·회전곱)을 끼워넣으면 지시 무시 + 일을 키우는 것. (단 그 지시가 명백히 틀렸을 때만 [[feedback_objective_judgment_no_sway]] 근거로 짧게 이의 — 단순 "더 정교함"은 이의 사유 아님.)

**How to apply:**
1. 사용자가 "이 셀/이 SKU/이 값으로" 지정 → **그 값 그대로** 수식에 박는다. 전체평균·비례배분·정규화 등 자체 가공 X.
2. 더 정교한 대안이 떠올라도 먼저 시킨 대로 한 뒤, 필요하면 "참고로 이런 방법도 있다" 한 줄로만. 실행은 지시 우선.
3. 관련: [[feedback_use_template_as_is]] [[feedback_dont_reask_explicit_instruction]].
