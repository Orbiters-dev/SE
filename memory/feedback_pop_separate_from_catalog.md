세은 교정 (2026-05-11): "pop는 카탈로그 작업이 아니기 땜에, 카탈로그 대신 POP" + "pop 항목 따로 만들어서 넣으면 돼"

**Why:** POP (Point of Purchase 매장·박람회 디스플레이)와 박람회 카탈로그는 별개 작업. 5/11 사고: POP 1종 전달을 "JP 박람회 카탈로그" 항목 안에 넣으려 한 게 오류. POP는 자체 트랙으로 진행되는 별도 작업.

**How to apply:**
- 일일 보고 기타 작업 / 주간 보고 등에 POP 작업 표기 시 → "POP" 단독 항목 헤더로 분리
- "JP 박람회 카탈로그" 와 "POP" 는 별개 헤더 (같은 박람회 맥락이어도 묶지 마)
- 다른 인쇄물/디자인 작업도 비슷한 분리 원칙 적용 가능 (리플렛 / 카탈로그 / POP / 패키지 디자인 = 별개)
