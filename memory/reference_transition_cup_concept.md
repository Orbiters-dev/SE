2026-10-01 세은 지시 (HARUKA様 신규·딸 이유식 중기·혼자 못 앉음 케이스):

**핵심:** 월령 미달이어도 바로 보류/클로즈하지 말고 **transition cup(이유식기 이행용 마그)** 컨셉으로 콜라보 제안. GROSMIMI 스트로머그는 哺乳瓶(젖병)→머그 이행기 아이에게도 맞는 상품.

**제안 흐름 (세은 확정 문구):**
1. 「혼자 마시는 씬」 무리하게 안 찍어도 된다고 안심
2. 젖병→머그 이행 단계 설명: **먼저 ストローのチューブ(대롱) 빼고 吸い口(꼭지)만으로 사용** → 점차 ストローマグ에 익숙해지는 과정
3. 「현재 젖병 사용 중이신가요?」 질문 (이행 단계 확인)
4. 이 **「조금씩 빨대에 익숙해지는 과정」 자체를 촬영**하는 방향 제안 (置き画·엄마와 함께 사용 OK)
5. 시간 걸리는 것 이해한다 + **참고 레퍼런스 영상 송부** + 무리 없는 범위에서 의향 확인

**적용:** 월령 6개월 미만~이유식 초중기, 혼자 음용 불가 인플루언서에게 리치아웃/상담 시. 제품은 PPSU ストローマグ(6개월~) 적합. 레퍼런스 영상은 세은이 실물 지정.
⚠️ 「견てくださる方にも伝わる」류 평범한 마무리보다 「どんな製品の特徴説明よりも伝わる」처럼 강조하는 톤을 세은이 선호 (五島様 건 교정).
