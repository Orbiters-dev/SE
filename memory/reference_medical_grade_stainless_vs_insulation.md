그로미미 ステンレスストローマグ 소구 시 구분:

- **保温・保冷** = 스테인리스 머그(이중벽 진공) **자체**의 기능. 의료 그레이드라서 강한 게 **아님**.
- **医療グレード(SUS316)의 고유 강점** = 「サビに強い・ニオイ移りしにくい・長く使える」 (녹·냄새·내구).

→ 영상/소구에서 "의료 그레이드라서 보온보냉이 좋다" 식으로 **묶으면 안 됨**. 의료 그레이드 메인 테마면 녹·냄새·내구를 주역으로.

**자연스러운 표현 (싸가지 X):**
「保温・保冷はステンレスマグそのものの機能で、"医療グレード"ならではの魅力は『サビに強い・ニオイ移りしにくい・長く使える』点になります」

**Why:** 2026-06-15 坂田様 대본 수정 시 세은 지시. 가이드라인 sus_category_A.html은 保温保冷도 포함하나, 의료그레이드 소구 핵심은 녹·냄새·내구.

## 保冷・保温 공식 스펙 = 「最大6時間」 (真空断熱) — 2026-09-18 라쿠텐 페이지 검증
- 라쿠텐 stainless_steel_strawcup_300 공식: **保冷・保温 最大6時間** (냉·온 동일, 真空断熱). 온도(℃) 수치는 페이지 미기재.
- ⚠️ **「6時間以上」는 과대표기** — 세은도 구두로 "6시간 이상"이라 했으나 공식은 **"최대 6시간"**. 소구/DM엔 반드시 「最大6時間」으로. (세은 구두 스펙도 공식 페이지 대조 후 사용)

## 우유/다양한 음료 대응 테마 (加藤様 2026-09-18) — 스테인리스 머그 소구 앵글
스테인리스 머그에 우유 넣으면 문제라는 인식 → 우리 빨대 꼭지는 물 외 우유·주스·이유식(점도·기압변화 민감 액체)까지 대응. 3포인트:
1. **밸브+에어홀** 압력차 조절 → 따듯한 우유 넣고 닫아도 내압으로 빨대에서 뿜어져 나옴/「우유가 빨대 타고 올라와 넘침」 문제 잘 안 생김
2. **保冷・保温 最大6時間** → 차가운·따듯한 음료 모두 적정온도로 휴대
3. **이음매 없는 내부** → 우유 등 오염물 잔류 어려워 위생적
