RPP 키워드 효율 점검·OFF 판정 규칙 (2026-09-17 세은 확정, 삐삐 영역).

**① OFF(제거) 임계 = 최소 ¥5,000 스펜드 + 전환0.**
- 「끄는 키워드 최소 5,000엔은 스펜드한 걸로 골라야댐」 (세은 직접). 기존 2-트랙 룰(¥3,000~4,500)에서 **¥5,000으로 상향**.
- ¥5,000 미만 전환0 = 표본 부족 → **OFF 불가·판정 보류·계속 소진 후 재판정**. 리포트에 "¥X 남음(¥5,000까지)" 표시.
- **판정 근거(¥5,000 스펜드해야 OFF 대상)를 리포트에 명시 기재**하라고 지시함.
- 2026-09-17 실측: 활성 상품 중 ¥5,000+ & 전환0 = **0건**(¥5,000 초과는 ストローマグ 保冷 ¥6,105뿐·전환 有). 즉 당장 끌 것 없음. ベビーマグ ¥2,862 = 도달 시 1순위.

**② 효율은 현재 RPP 활성 상품만.**
- 비활성/중복 리스팅(_copy·_ss·onetouch_copy)은 집계에서 제외. **정본 = 콘솔 상품 목록 스크린샷**(세은 제공).
- 활성 상품 슬러그(2026-09-17): stainless_steel_strawcup_300 · grosmimi_ppsu_strawcup300 · grosmimi_ppsu_onetouch_srawcup · grosmimi_srawnipple_2-4 · grosmimi_srawnipple_2-2.
- 데이터에 비활성 상품 slot이 섞여 있으면 활성 화이트리스트로 필터 후 재집계.

**③ 리포트 포맷 지시:** 상품별 탭 구조 · 일본어 키워드 옆 한국어 번역 병기 · 스펜드 금액 병기 · 대체어는 근거(3소스) 명시.
