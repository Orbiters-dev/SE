# 오답노트 2026-07-01

메타 자동화↔intelligence 루프 설계 세션 ([[project_meta_content_intelligence_loop]]). 아키텍처 파악·검증은 잘 됐으나 **커뮤니케이션에서 3건 교정**.

1. **「뭔소리야」 ×2** — Phase 진행순서를 `§23 MetaAdExecution 타이머 ON` 같은 내부명칭으로 설명 / 이후 엔드포인트·토큰·cap을 나열해 설명. → 쉬운 말로 재설명하니 이해. **내부 식별자로 세은한테 설명 금지.** [[feedback_explain_plainly_no_jargon_no_preamble]]
2. **「니가 찾아」** — orbitools 대시보드 read 토큰을 세은한테 「있는지 알려줘/발급해줘」 물음. 실제론 `.env`에 `ORBITOOLS_DASHBOARD_ID/PW`·`DK_SE_READ_TOKEN`·`DATAKEEPER_API_KEY` 다 있었음. **직접 파악 가능한 건 묻지 마 재위반** — 물어보기 전에 .env/secrets/기존 도구 먼저 grep. [[feedback_self_first_no_wongi_default]]
3. **「구구절절 X」** — 원기 전달용 복붙 메시지에 배경·실측 확인상태를 장황하게 넣음. → 「필요한 것만」. 전달 메시지 = 요청 항목만. [[feedback_explain_plainly_no_jargon_no_preamble]]

**핵심:** 조사·검증은 깊게, 세은/원기 대면 출력은 짧고 쉽게. 둘을 분리.
