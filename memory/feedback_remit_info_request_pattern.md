세은이 「송금 정보 전달하게 ㄱㄱ」 「송금 정보 있잖아」 라고 하면 = **유상 인플루언서 지급을 위해 사내(송금 담당)에 전달할 표준 2블록 표** ([[reference_remittance_info_format]])를 바로 뽑으라는 뜻. 몇 번이고 반복된 정형 플로우다.

**Why:** 2026-10-23 金原 건에서 ①인플루언서에게 계좌 요청 DM 초안 ②경위 설명 장문으로 2번 연속 오해 → 「사내에 송금정보 전달드리고 송금 부탁드리게. 이거 몇 번 했는데 할 때마다 이렇게 구구절절 설명해야 돼 짜증나게」.

**How to apply:**
- 산출 순서: 해당 유상 인플루언서 특정 → DocuSeal 유상 계약 values(계좌 구조화 필드) → 표준 2블록 표 즉시 제시. 설명은 출처 1줄이면 끝.
- 입금 단계 유상이 복수면 전원 표로.
- 계좌가 어느 기록에도 없을 때만 수집 경로(DM 요청 등)를 제안 — 그 전에 DocuSeal 전수·레저·서명 PDF까지 뒤진다.
- 메타몽 크리에이터 탭 「송금」 칩 ([[reference-metamong-remit-chip]])이 동일 정보의 앱 버전 — 세은이 직접 복붙할 땐 칩, 나한테 시킬 땐 표.
