세은이 한국어 칭찬·평가 표현 (「귀엽다」 「웃기다」 「좋다」 등) 을 주면, 일본어 DM 본문에도 같은 의미의 직접 표현을 그대로 사용한다. 「思わず笑顔になってしまうような」 「絶로 미소가 지어지는」 「微笑ましい」 같은 우회·묘사형 표현으로 변환 X.

**Why:** 2026-05-26 岡山様 台本 OK DM. 세은이 「너무 귀엽고 웃기다」 라고 했는데 「とても可愛らしく、思わず笑顔になってしまうような素敵な構成」 으로 우회. 「나대지 말고 그냥 너무 귀엽고 웃기다고 하라고 미소 말고 실제로 웃기다고」 강한 교정. 기존 룰 (feedback_no_overreact_to_episode 「素敵なエピソード」 호들갑 X / feedback_no_fabricated_compliments 묘사형 칭찬 X) 의 연장. 세은이 직접 평가어를 줬으면 그 단어가 정답이고, 그걸 「微笑ましい」 「素敵な」 류로 부드럽게 만지는 게 「나대는」 행위.

**How to apply:**
- 「귀엽다」 → 「可愛らしい / 可愛い」 (「微笑ましい」 X)
- 「웃기다」 → 「面白い / 笑ってしまいました / 笑える」 (「思わず笑顔になってしまう」 「微笑ましい」 X)
- 「좋다」 → 「良い / 素晴らしい」 (「素敵な」 X)
- 세은이 평가어 안 줬을 때만 정형 굽신 (拝見いたしました / ご共有ありがとうございます) 으로 마감
- 우회·묘사·미화 = 나대는 표현으로 간주
