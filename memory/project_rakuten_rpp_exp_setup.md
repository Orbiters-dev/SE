세은이 라쿠텐 매니저 추천으로 **RPP-EXP(検索連動型広告-エクスパンション)** 테스트 캠페인을 2026-09-09 세팅·활성화했다.

## RPP-EXP란 (우리 RPP와 별개 상품)
- 우리 라쿠텐 상품을 **楽天市場 밖 Google 지면**(검색 스폰서 영역·쇼핑탭·이미지탭·YouTube·제휴 사이트)에 자동 송출하는 CPC 광고. 소재는 RMS 상품정보 자동 연동(배너 제작 불필요).
- 노출 형식: Google 스폰서 카드 = [상품이미지 + 상품명 + 가격 + 楽天市場]. (도식 `.tmp/rpp_probe/google_cases/captainec_expansion_01~04.jpg`)
- 우리 현행 RPP(楽天市場 **내부** 검색연동, 삐삐 키워드·입찰 운영)와 **별도 콘솔·별도 상품** → 동시 운영 정상 (`/rpp/` vs `/rppexp/`).
- 원 매뉴얼: 라쿠텐 점포운영Navi ID 000050147. 우리 번역본 `s\performance marketing\Rakuten\RPP-EXP_개요_한국어번역_20260728.html`.

## 구조·리스크 (삐삐 판정 시 유의)
- **전 SKU 자동 게재 = 블랙리스트(옵트아웃) 방식**: 캠페인 켜면 RMS 등록 상품 거의 전부 자동 대상. 빼려면 「除外商品」에 개별 등록. (주력만 화이트리스트 지정은 불가.)
- 세은이 除外商品에 다수 등록함(스토로&니플 세트·스텐/PPSU `_copy` 중복리스팅 등, 확인 11개+·전체수 미확인) → 주력 집중 목적으로 추정(미확정).
- 게재 요건: 상품별 **흰배경 이미지 + 카탈로그ID(JAN)** 필수, 미충족분은 자동 미게재.
- **월예산 초과 가능**(Google 사양) — 5,000엔 딱 안 멈출 수 있음. CPC 설정 범위 10~10,000円(대행사 기사 근거, 콘솔 실물 미최종확인).
- ROAS 주의: 楽天 외부 유입이라 우리 RPP(8월 282%·9월 347%)보다 낮게 나올 수 있음. 무료 Google 오가닉 트래픽을 유료로 사는 카니발 가능성.
