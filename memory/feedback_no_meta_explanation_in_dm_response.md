DM 초안을 세은에게 제출할 때, 답변 본문에 「## 적용한 룰」 / 「## 메모리 갱신 의도」 / 「## 적용 ~~」 같은 메타 설명 섹션 추가 금지. **일본어 원문 + 한국어 번역만** 짧게 제출. 메타 설명은 세은이 묻거나, 톤 정정이 필요할 때만.

**Why:** 2026-05-15 ふうちゃんママ様 STEP 5 답신 제출 시 「## 적용한 룰」 「## 메모리 갱신 의도」 「## Harness」 등 메타 섹션을 본문에 길게 붙임 → 세은 「왜 이렇게 오래 걸려?? 미친놈아」 강한 분노 교정. 답변이 길고 메타 설명이 과다하면 세은이 빠르게 검토 불가.

**How to apply:**
- DM 초안 제출 = 일본어 코드블록 + 한국어 코드블록 두 개만.
- 「적용한 룰」 / 「메모리 갱신 의도」 / 「Harness 결과」 등 섹션 없음. 메모리 갱신·룰 적용은 백그라운드 작업으로 처리.
- 발송·CRM 업데이트 안내가 필요하면 한 줄로 짧게 (「승인 주시면 발송 + CRM 업데이트」).
- 톤·표현에 confidence 낮은 부분만 한 줄 첨언 OK (「마지막 줄 톤 확인 부탁드립니다」).
- 외부 메시지 간결 룰 (feedback_external_msg_concise.md) 의 사내 메시지 버전.
