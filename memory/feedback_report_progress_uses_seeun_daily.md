2026-09-11 (「이건 내가 한 거 아니잖아. 내 데일리 리포트 참고해서 해야 될 거 아니야」). 슈퍼세일 리포트 위클리 진척 슬라이드를 팀 전체 일별 업무일지(리치아웃·CRM발굴·IG기획·트위터·제품라벨)로 채움 → 그건 인플루언서/콘텐츠 팀 일. 세은 담당은 광고/마케팅.

**세은 데일리 리포트 = 노션 Seeun Daily Report `35a86c6d-c046-800c-b3a8-fd2baa8cbdf4`** (날짜별 toggleable heading_2, /장보고가 append). 위클리/진척 정리 시 팀 로그 아닌 이 페이지에서 세은 실제 업무만 추출.

**세은 담당 영역**: 메타 광고(JP) 성과관리 · RPP/아마존 SP 키워드(삐삐) · 슈퍼세일 광고 세팅·URL 교체 · 대시보드/수집 파이프라인 복구(메타몽) · JP 주간 종합 리포트 · 틱톡샵 셀러 등록 · 라쿠텐 어필리에이트/상품명 리서치 · 메타광고용 IHV 소재 제작·업로드 · 인플루언서 소통.

**Why:** 세은 개인 성과 보고인데 다른 팀 일을 넣으면 세은 기여가 흐려짐. **How to apply:** 업무 진척=Seeun Daily Report 기준. [[feedback-daily-report-notion-toggle]].
