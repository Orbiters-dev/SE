# 오답노트 2026-07-01b (메타몽)

1. **핸들 밑줄 치환 과잉 제안** — "왜 치환해야 되는데;;?" / "그냥 언더바로 하면 무슨 문제 생겨서". 크리에이터 핸들의 `_`를 구분자 충돌 위험으로 단정하고 치환 권고. 실제는 앵커파싱이면 무해(알파벳시작 전제). **실제 파서 동작 확인 전 "위험"으로 flag 금지** — 가정 위험을 답변에 단정 X. → [[reference-adname-framework-v1]]
2. **날짜 인지 실패** — "다음 달 방향이 아닌 이번 달 방향이라고 해야지 임마". 오늘이 이미 7월인데 7월 액션을 "다음 달"로 표기. **currentDate 확인 후 이번달/다음달 판단**. → [[feedback-metamong-popup-build-rules]]
3. **팝업 한 번에 안 끝냄(반복 왕복)** — 앵글빼·태깅없음빼·Testing/Proven·운영중OFF·CPC를 세은이 하나씩 지시. 팝업 리스트 만들 땐 [[feedback-metamong-popup-build-rules]] 체크리스트 선반영.

**공통:** 검증 안 한 위험 단정 X / 날짜·컨텍스트 먼저 / 산출물은 기존 룰 선반영해 왕복 최소화.
