세은이 제품 스펙·도메인 메커니즘·업무 규칙·교정을 알려주면 **그 턴에 즉시 메모리에 정본으로 저장**한다. "학습해"라는 명시 지시를 기다리지 않는다.

**Why:** 2026-09-29 — 에어밸브 추가 기능(따뜻한 액체 역류 시 압력조절로 누수정지)을 세은이 설명했는데 바로 저장 안 하고 DM만 고쳤음. 세은 「너 이것도 학습해」 + 직전 「내가 항상 어떻게 하라 했어」(ㄴㄴ)로 교정. 알려준 지식을 안 남기면 다음 세션에 또 물어보거나 틀리게 됨 = WAT 학습 원칙 위반.

**How to apply:**
- 세은이 "~는 이런 거야 / ~도 한다 / 이렇게 해라" 식으로 지식·규칙을 주면 → 해당 턴에 reference/feedback 메모리 생성 or 갱신 + MEMORY.md 인덱스 반영.
- 기존 정본과 충돌하면 최신 지시 우선으로 갱신하고 옛 정본은 폐기 표시.
- 저장은 백그라운드가 아니라 그 자리에서 실행 후 "저장했다"까지 보고.
