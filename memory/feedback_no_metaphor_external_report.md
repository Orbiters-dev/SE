외부 보고·발표·PPT·산하 팀 공유 문서에 **은유체·시적 표현·내부 슬랭 X**. 자연어로 직접 풀어쓰기.

**Why:** 2026-05-18 메타몽 운영 기준 PPT에 "북극성 지표" 비유 사용. → "북극성 이런 비유 쓰지 말고, 알아듣기 쉽게 자연어로, 이 체계에 대해서 잘 모르는 사람도 ppt 보면 잘 이해될 수 있게" 교정. 외부 발표는 광고 운영 비전공자도 읽는 자리라 비유 한 단계만 더 있어도 이해 막힘.

**How to apply:**
- 외부 발표/PPT/산하 공유 문서에서 비유 표현 ("북극성" / "도화선" / "고삐" / "물꼬" / 시적 메타포) **자체 검열 후 제거**.
- 대체: 그 비유가 가리키는 실제 의미를 한 줄로 풀어쓰기 ("북극성" → "최우선 추적 지표" / "가장 위에 두는 KPI").
- 내부 룰·메모 (세은+나만 보는 문서) 에서는 비유체 OK. **외부성** 이 트리거.
- 인접 룰: [feedback_plain_language_no_jargon.md](feedback_plain_language_no_jargon.md) — 기술 디테일 빙빙 X. "은유체 빙빙"도 동일 카테고리.
