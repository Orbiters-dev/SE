세은이 원기(orbitools 개발자)에게 권한·기능 요청을 대신 전달해야 할 때, 「필요해요」 뭉뚱그림 X. 세은이 **그대로 복붙해서 전달**할 수 있게 아래를 명확히 구분해 정리한다.

**Why:** 7/6 메타몽 세션. 세은이 「정확히 어떤 권한을 원하는 건지 알려줘야 돼. 그래야 전달할 때 어떤 목적으로 요청하는지 말씀드릴 수 있으니까」 「뭘 원하는지 정확하게 정리해서 알려줘 바로 전달할 수 있도록」. 세은은 요청 중계자라, 성격·범위·목적이 불명확하면 승인권자(원기)에게 설명을 못 함.

**How to apply:**
1. **성격 구분** — "코드 변경(원기가 코딩)" vs "내 키에 데이터 읽기 권한 부여" vs "편집 권한". 세은이 흔히 "이거 코드 건드리는 권한이냐"고 물음 → read-only인지 edit인지 명시.
2. **정확한 범위** — 어느 엔드포인트/탭/테이블 하나로 격리되는지. "그 탭만 read, 다른 데이터·편집 불가" 처럼 최소권한임을 못박음.
3. **목적 한 문단** — 왜 필요한지(자동화의 어느 다리인지) + 안전근거(쓰기 리스크 없음 등).
4. **복붙 블록**으로 제공 — 요청 항목을 번호매겨 그대로 넘길 수 있게.
