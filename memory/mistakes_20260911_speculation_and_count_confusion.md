2026-09-11 슈퍼세일(9/4~9/11) 6월 대비 매출 -64% 원인 리포트/노션에서 강한 교정 2건.

**① 근거 없는 추론 창작 (「이거 치워 스테인리스 신제품을 언제 냈어 나대지 마」)** — 6월 대비 스테인리스 급감 원인을 "6월 스테인리스 신제품 런칭 슈퍼세일 첫구매 폭발 vs 9월 3개월차 수요 소진"이라 리포트 hi박스·노션 bullet에 창작해 넣음. 스테인리스는 신제품이 아니었음. 데이터로 확인된 사실(전환 붕괴·CVR 0.85%→0.11%·유입=메타 클릭 +57%)만 남기고 배경 원인은 "별도 실측 확인 필요"로만 표기. **Why:** [[feedback-canonical-km-source-not-improvise]] 재발 — 검증 안 된 배경은 산출물에 넣지 말 것. **How:** 원인 서술은 데이터 직접 확인분만. 신제품/런칭/시즌 등 배경 주장은 사실 확인 후에만.

**② 같은 지표를 다른 정의로 오락가락 (「9월 니는 59개라고 했잖아 장난하나」)** — 세일용 SKU 카운트 3종(주문 건수 59 · 상품 라인 62 · 판매 수량 63)을 구분 없이 섞어 제시. 팀원 "판매 건수"=상품 라인 수(62). **How:** 건수류 지표는 정의(주문/라인/수량) 먼저 못박고 일관되게 사용. 팀 대조 시 팀원 정의(판매건수=라인 · 평단=매출÷수량) 먼저 확인.

**③ 리포트 전체 소스 통일 누락 (「제대로 하는 게 없네 하나하나 다 말해줘야 돼」)** — 6월비교·스테인리스 슬라이드는 새 소스(주문 API 9/11)로 바꿨는데 상품3갈래 표만 옛 소스(get-item-list 9/10, 주문 50) 방치 → 표 간 불일치. **How:** 소스 교체 시 파생 표 전부 일괄 통일(grep로 옛 소스 잔재 0 확인).
