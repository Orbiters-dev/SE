# 오답노트 2026-06-16 (인플루언서 DM 세션, 강한 교정 2건)

## 1. 児玉様(ohana) 「전부 완료」에 마무리 DM 누락
- 세은 「児玉様 전부 완료」 → 나는 메모리만 갱신하고 종료
- 세은 「쌰갈 마무리 멘트 디엠을 줘야 할 거 아냐」 강한 교정
- → [[feedback_completion_report_means_write_closing_dm]] 신설. 「완료」 = 마무리 DM 작성 신호.

## 2. 牛込様(nico) 메모리 오기 근거로 틀린 충돌 고지
- 세은 「牛込様에게 6월분 영상 상담 DM」 지시 → 나는 nico.md의 5/29 「1편이 끝 / 6월분 게시 X」 기록을 근거로 "5/29 종결 방침과 충돌, 6월분 다시 진행 맞냐" 고지
- 세은 「뭔소리야?? 6월분 접은 적 없어」 → 메모리 오기였음
- 실제 계약 = Reels 2本(5월분 종결 + 6월분 진행 중). nico.md 정정 완료.
- **교훈:** 메모리 기록을 근거로 세은 지시에 충돌 고지하기 전, 그 기록이 ⚠️ 표시·자기모순 있는 stale일 가능성 의심. 특히 「종결/X」 류 단정 기록은 한 번 더 의심. 충돌 고지 자체는 맞으나(객관 판단 룰) 근거가 오기면 헛발질.
