# OKR 표 "Last Week" 칸 = 직전 노션 페이지의 "This Week" 값. 다른 데서 찾지 마

**Why:** 2026-05-07 W18 OKR 작성 시 "Last Week 콘텐츠 누적 / IG Followers 어디서 봐?" 묻기 → 세은 "저번 notion 참고하라고". W17 페이지(`34b86c6d-c046-80be-a58f-d1b37b5414cc`)의 This Week 값(콘텐츠 71 / IG 1,229)이 W18의 Last Week 값으로 그대로 옮김. 누적치는 페이지 간 연속 업데이트가 정답. 다른 시트/DB 뒤지지 말 것.

**How to apply:**
- JP Weekly Reports DB (`2fc86c6dc0468000a671e3ed32083c8f`) Seeun 페이지 작성 시:
  1. 직전 같은 사람(Seeun) 페이지 fetch → "This Week" 칸 값 복사
  2. 이번 페이지 "Last Week" 칸에 그대로 붙여넣기
  3. "This Week" 칸 = Last Week + 이번 주 신규
- 페이지 식별: 같은 사람 (Seeun/Kazuki/Jisun) + 직전 Report Date
- IG followers 등 외부 자체 데이터는 직접 도구로 fetch (별개 룰)
