## 3. Windows 자원 도구 선택 실수

bash 환경에서 `schtasks /query | grep ...` 으로 Windows Task Scheduler 검색. 출력 인코딩이 cp949라서 한국어/특수문자 grep 매칭 깨짐. 빈 결과 → "등록 안 됨" 으로 잘못 단정.

PowerShell `Get-ScheduledTask` 한 번에 5개 즉시 식별 (KSE/Rakuten Task 모두).

원칙: Windows 시스템 자원 (Task Scheduler / 레지스트리 / 이벤트 로그 / 서비스) 조회는 **PowerShell 우선**. bash + 한국어 도구 출력 신뢰 X.

→ CLAUDE.md line 31~34 + `reference_windows_resources_powershell.md` 신규.
