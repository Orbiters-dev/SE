# 장보고 신규 광고 표 성과 컬럼 + 세은 편집본 취급

세은 지시 (2026-07-09): 「이번 주 신규 광고 (7/3~7/9 등록, 전부 WL 영상) 간략하게 효과도 같이 기재해 주고, **다른 건 아무것도 건드리지 마**」

**Why:** 신규 광고 표가 등록일/광고/캠페인/URL만 있어서 성과를 별도로 봐야 했음. 그리고 세은이 그날 토글을 이미 직접 재편집한 상태(섹션 재배치·문구 축약)라, 재작성하면 세은이 본 컨텍스트가 깨짐 (feedback_notion_page_no_archive_only_append 계열).

**How to apply:**
1. **신규 광고 표 컬럼 (앞으로 기본)**: 등록일 / 광고 (인플루언서) / 캠페인 / **지출(누적) / CTR / CPC / CPLPV** / URL — 성과는 Graph API ad-level, 각 광고 등록일~보고 당일 누적 (time_range 윈도우 시작을 등록 컷오프로, 등록 전 spend=0이라 단일 쿼리 가능). 헤더에 「(누적)」 라벨.
2. **세은이 수동 편집한 노션 페이지 수정** = 지시받은 블록만 DELETE + `after` 파라미터로 같은 자리 삽입. 전체 재작성·재append 금지.
3. **관찰 (7/9 세은 수동 편집, 다음 회 선반영)**: 메타몽 앱·게이트·훅 등 메타 관련 앱 작업 블록을 §3 기타에서 **§2 메타 광고 (JP) 안으로 이동**시킴 + Headline 문장 축약 + CRM 헤딩에 「- 대기 중」 병기. 다음 장보고부터 메타 관련 앱/게이트/메일 작업은 §2 하위 ◆ 블록으로 배치.
