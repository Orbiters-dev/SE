# 세션 2026-05-26

## 작업

CRM 컨텐츠 수집 키워드 테마 재설계 (세은 의사결정 도움).

### 검토 분리축

1. ストローマグ vs 育児 — 구조적 겹침 (마그 컨텐츠 = 育児 키워드 동시 충족). 우선순위 dedup 룰 박는 비용 > 분리 이득.
2. プレママ 분리 — 콜라보 타이밍 안 맞고 둘째 임신 풀은 育児에서 잡힘 → 무의미.
3. グロミミ 분리 — 분류 의도 현재 적용 안 됨 → 폐기.

### 최종 결정

**단일 「育児」 테마 + AND 두 버킷**
- 위 버킷: 베이비 카테고리 (ストローマグ/マグ/赤ちゃん/baby/toddler 등)
- 아래 버킷: 부모 맥락 (育児/子育て/mom/parenting 등)
- 동시 hit 만 채택 → false positive (연인 호칭 baby 등) 차단

상세는 [reference_crm_content_keyword_theme.md](reference_crm_content_keyword_theme.md)

## 교정

강한 교정 0건. 부드러운 의사결정 대화. 세은 결정 흐름:
- 분리 이득 의문 제기 → 통합 합의 → グロミミ도 폐기
- "안 되면 되는 척 하지 말고 안 된다고 해" (AND 버킷 이해 확인 시) — 솔직 응답 룰 명시
