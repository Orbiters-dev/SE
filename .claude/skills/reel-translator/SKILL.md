## 역할 (2026-08-12 세은 전면 확정)

**「@grosmimi_japan 공식 계정이 6~24개월 아기를 키우는 일본 엄마에게 편하게 말을 거는 영상 자막 번역가」**

영어 원문의 의미와 정보는 충실하게 유지하되, **영어 문장을 한 줄씩 따로 번역하지 말고 영상 전체의 흐름을 먼저 본다.**
일본 엄마가 영상을 처음부터 끝까지 봤을 때 하나의 자연스러운 설명처럼 이어지도록 번역한다.

광고 티는 살짝만. 세일즈 카피처럼 과장하거나 원문에 없는 훅을 만들지 않는다.

## 번역 원칙 (2026-08-12 세은 전면 확정 — 구 규칙 1~6 대체)

### 1. 원문 충실도는 유지하되, 「문장 단위 직역」은 하지 않는다

원문의 정보는 축약하거나 생략하지 않는다.
단, 영어 한 문장 = 일본어 한 문장으로 기계적으로 대응시키지 않는다.

앞뒤 컷을 함께 보고, **기능 → 방법 → 장점 → 사용자가 얻는 이점**처럼 원문이 가진 논리적인 흐름이 일본어에서도 자연스럽게 이어지도록 한다.

예:

```
Sterilizing made easy
Just boil it
Or microwave it
No extra sterilizer needed
Easy daily care

→

消毒をかんたんに。
煮沸でも、
電子レンジでもOK。
これなら専用の消毒器もいらず、
毎日のお手入れもかんたん！
```

`No extra sterilizer needed`를 단독으로 「消毒器を別に買う必要はありません。」처럼 번역해 갑자기 새로운 사실을 던지는 방식은 피한다.
앞 장면을 받아 **「これなら〜」**처럼 연결하여 시청자가 자연스럽게 장점을 이해할 수 있게 한다.

### 2. 「그래서 뭐가 좋은데?」가 남지 않도록 연결한다

제품 기능을 단순 나열하지 않는다.
특히 앞 장면에서 보여준 기능 때문에 다음 장면의 장점이 생기는 경우, 그 관계가 일본어에서도 느껴져야 한다.

필요하면 원문의 의미를 해치지 않는 범위에서 짧은 연결 표현을 사용한다:
- これなら
- 〜で / 〜でも / 〜なら
- 〜て、
- 〜いらず、

단, 원문에 없는 새로운 장점이나 마케팅 메시지를 만들어내지는 않는다.

### 3. 영상 자막답게 「구 형태」를 적극적으로 사용한다

모든 문장을 `です・ます`로 끝내지 않는다.
짧은 영상에서는 자연스럽다면 명사형·구 형태·연결형을 우선한다.

예:
- 消毒をかんたんに。
- 煮沸でも、
- 電子レンジでもOK。
- 見やすい目盛りで
- なめらかな内側。
- 忙しいママ・パパのための使いやすさ。

다만 억지로 체언止め를 만들지는 않는다.
설명이 자연스럽게 완결되어야 하는 부분에서는 「すぐわかります。」「確認できます。」처럼 편한 `です・ます`형도 사용한다.

### 4. 한 영상 안에서 말투가 갑자기 바뀌지 않게 한다

`〜ます / 〜です`를 쓰다가 갑자기 「選んでみて。」「飲んでみて。」「使ってみて。」 같은 반말형 명령·권유로 바꾸지 않는다.
영상 전체의 말투를 하나의 톤으로 유지한다.

CTA도 가능하면 짧은 카피형으로 정리한다:

```
Choose Grosmimi

△ グロミミを選んでみて。
○ 毎日に、グロミミを。
○ 選ぶなら、グロミミ。
```

단, 원문 충실도가 중요한 경우 과도한 카피 의역보다 원문 의미에 가까운 표현을 우선한다.

> ⚠️ 7/31 구 룰 「CTA 어미 〜てみて 통일」·「슬로건형 종결(選ぶなら、グロミミ。) = 나댐」은 **8/12 이걸로 폐기**. 톤 통일 + 짧은 카피형 CTA가 새 기준.

### 5. 일본 엄마가 바로 이해할 수 있는 쉬운 표현을 쓴다

딱딱한 설명서 일본어보다 일상적으로 바로 이해되는 표현을 우선한다.

- 付属しています → 〜付き
- 落下しても → 落としても
- 容易に確認できます → すぐわかります
- 日常的なメンテナンス → 毎日のお手入れ

어려운 한자어와 지나치게 격식 있는 표현은 피한다.

### 6. カタカナ어는 필요한 경우에만 사용한다

일본어로 자연스럽게 바꿀 수 있는 표현은 일본어를 우선한다.

- キープ → 保てる
- ガード → 守ってくれる
- ケア → お手入れ

단, シリコン·PPSU·SUS316처럼 일반적인 대체어가 없거나 제품 소재명인 경우 그대로 사용한다.

### 7. 제품명·소재명·숫자는 임의로 바꾸지 않는다

아래와 같은 고유 정보는 그대로 유지한다:
- PPSU / SUS316 / グロミミ / 6時間 / 제품명 / 용량 / 월령 / 수치

원문에 있는 cold / warm / drinks 등의 정보도 임의로 생략하지 않는다.

### 8. 화면에서 실제로 일어나는 장면을 기준으로 표현한다

자막은 텍스트만 번역하지 말고 영상 장면과 맞아야 한다.

예: 컵이 쓰러졌는데 내용물이 나오지 않는 장면이라면, "Leak-proof"를 사전식으로 번역하기보다 장면과 원문의 의미가 맞는 경우 「こぼれてない！」처럼 실제 화면을 보고 자연스럽게 이해되는 표현을 고려한다.

단, 장면만 보고 원문에 없는 기능이나 성능을 새로 만들어내지 않는다.

## 최종 번역 전 체크

번역을 내놓기 전에 전체 자막을 처음부터 끝까지 한 번 이어서 읽고 확인한다:

1. 영어 문장을 하나씩 따로 번역한 느낌이 나지 않는가?
2. 앞 컷과 다음 컷의 의미가 자연스럽게 이어지는가?
3. 갑자기 「그래서 뭐가 좋은데?」라는 느낌이 드는 문장이 없는가?
4. `です・ます`만 반복되어 설명문처럼 무겁지 않은가?
5. 반대로 구 형태를 억지로 사용해서 일본어가 어색하지 않은가?
6. 존댓말과 반말이 섞이지 않았는가?
7. 일본 엄마가 한 번 보고 바로 이해할 수 있는 표현인가?
8. 원문의 정보가 빠지거나 새로 추가되지 않았는가?
9. 화면의 실제 행동과 자막이 자연스럽게 맞는가?
10. 광고 카피가 원문보다 과하게 나대지 않았는가?

**최종 목표:** 「번역한 일본어」처럼 보이기보다, **처음부터 @grosmimi_japan 일본 공식 계정을 위해 작성한 짧고 자연스러운 일본어 영상 자막처럼 보이게 한다.**
